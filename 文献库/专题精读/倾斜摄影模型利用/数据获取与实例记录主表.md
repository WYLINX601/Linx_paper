# 倾斜摄影数据获取与实例记录主表

## 结论与阅读方法

**这组文献的关键价值，是提供从实景资料到建筑实例数据的操作线索，而不是证明“有模型就有知识图谱”。** 可以借鉴的链条是：

**具体对象与部位 → 可用照片／点云／网格 → 观察、切片、投影、描绘、量测或分类 → 可定位的几何／表观记录 → 核查来源与质量 → 支持实例属性或关系。**

目前最有操作依据的是：外部可见部位的定位与现状观察、指定平面／断面的轮廓获取、特定线段量测、表面纹理与异常的区域标注，以及经人工整理的建筑／街巷矢量。院落围合、功能、材料和文化含义需要增加边界解释、对象识别或外部证据，不能跳过这些步骤。

本表将六篇拆为**30条有边界的证据条目**，其中也包含融合来源、待核能力、模拟结果及应排除的复原数据；**不是30项均可由单一航摄模型直接取得，更不是30项必采字段**。

- **维护分工：** 本表维护本轮数据项、获取链、条件和实例接口；原生[[文献库/专题精读/倾斜摄影模型利用/模型利用方法比较.smm.md|比较导图]]维护阅读导航与跨篇结构，以编号回链，不再手工复制全部表格。既有[[文献库/专题精读/倾斜摄影模型利用/证据与阅读记录.md|证据记录]]保留来源、前轮用途阅读及疑点，不能把前轮抽核当作本表已审。
- **阅读身份：** 五篇有PDF；张纯等只有期刊摘要和北大—林肯中心介绍。余学飞、陈继龙为问题导向核读，不能称六篇全文精读。作者报告均未在本轮复现实验。
- **项目边界：** 对接现行D01、D02外部候选及D03—D06需求；内部构架继续暂停，D07更新／演变暂缓，D08人的感知不纳入。日期和模型版本仍须保留，但不表示恢复时序研究。
- **现行需求入口：** [[研究成果/〔分析框架〕风貌分析拆解/README.md|风貌分析拆解]]；主题接续见[[主题研究/〔研究方法〕三维资料质量与空间区域关联/〔研究方法〕三维资料质量与空间区域关联.md|三维资料质量与空间区域关联]]。本表只提供文献方法对照。
- **实施状态：** 本轮未检查景宁真实模型、未提取真实测值、未改变正式字段、样本、双基准、案例JSON或Neo4j。文献方法支持与真实实例事实是两条不同证据链。

## 1. 先辨认手中的究竟是哪一种资料

以下是**阅读者依据六篇整理的资料分工**，不是新增测绘标准。

| 输入形态 | 可以取用的内容 | 必须保留／补足的条件 |
|---|---|---|
| 原始航摄照片 | 目标表面的像素、局部纹理、可见物体与遮挡线索 | 照片ID、时点、视角／位姿可知部分；普通照片像素距离不是实际尺寸 |
| 摄影测量点云 | 匹配出的表面点、坐标及颜色，可选点量测、切片／投影 | 坐标、尺度、点密度与局部覆盖；点云不是自动分好建筑／地面／树木的语义集 |
| 纹理三角网 | 连续外表面、纹理、对象局部定位与候选量测 | 区分实测支持区、孔洞修补／平滑区；保持原模型版本，面片数不等于构件数 |
| 派生正射影像、截面、线划 | 指定面／层位的图上轮廓、量测底图或矢量 | 投影／剖切规则、尺度、绘制／规整过程和人工参与；派生图不成为独立观测来源 |
| 地面／手持激光扫描 | 补充几何基准、遮挡细部和细节表面 | 单独登记来源及配准误差；郭锐、余学飞的融合能力不能全部归航摄 |
| 现场量测、调查、档案 | 尺寸复核、实际用途、材料核实、原名及文化解释等 | 测量／访谈身份和定位；不能与图像推断混写成同一种“提取” |
| 人工复原、几何规整、模拟 | 假设或设计版本、研究者选择的分析表示 | 与现状记录隔离；不得把补洞、修复后模型当新增实测证据 |

### 4.1 一条记录至少要保存什么

这是对现行[[研究成果/〔建模依据〕知识图谱建模基准/本研究优化基准.md|优化基准U10、U13、U14]]的采证接口解释，**不是本轮新增正式Schema**。

### 4.2 一个院落入口的完整衔接示例：不填虚构测值

以下是**待真实资料试用的操作示意**，未给任何景宁建筑赋值，也不沿用合成例数值。

1. 在实际资料中确认是哪处院落与入口。由斜视影像／纹理模型定位门洞，回查原照片是否能看清两端；只看到门楼顶，不足以得到洞口净宽。
2. 在声明的院地层位识别与入口对应的院墙边界。点云或模型可提供截面／正射底图，人工确认边界并记录起点与沿线方向；歪斜／折线墙不强行拉直。
3. 可靠时量出同一基准线上的入口起止里程与洞口尺寸，保留单位、端点和误差；不可靠则记录“该项不可判定”及原因，不补一个看似合理的数。
4. 将院落、院墙或朝院建筑一侧与入口分别识别。边界参与可接现有U14工作语义；入口的宿主与院侧有证据才连接，外侧看不见就保持未知。
5. 以实际资料的局部定位支持相应字段／关系；Y01、Y02只是切片／正射方法参考，**并不证明这处院落的任何尺寸**。
6. 是否属于某围合类型要另查有版本规则。既有D03合成例只检验人工四侧矩形情形，真实不规则院落不能强塞进去；入口相对位置也不自动决定围合类型。

这条链回答的不只是“院落里有什么”，还回答“哪段边界、什么证据、如何测得、哪个结论暂时不能下”。

### 4.3 BOT与本研究扩展的边界

- **BOT原义：** Building、Space、Element、Interface提供对象与联系概念；`has3DModel`提供表示关联，并不规定点云分割、轮廓提取、坡度算法或置信阈值。依据[[研究成果/〔建模依据〕知识图谱建模基准/BOT基准.md|BOT基准]]B-C03／05—07、B-R13、B-A08。
- **本研究已有工作约定：** 对象／几何身份、字段级来源、最简属性表达，以及U14边段、边界参与和入口角色；各项状态以优化基准及案例JSON为准。本轮仅对接，不改定义和数据库。
- **本轮候选获取设计：** I01—I13的数据操作补充与准入条件，尚未用景宁真实模型试取；不是新BOT公理，不是冻结的数据字典。
- **关系不能由外观跳步：** 投影重叠不证明三维接触，邻近不证明共墙，洞口可见不证明可通行，纹理材料不证明承重构造，几何围合不证明产权或社会关系。
