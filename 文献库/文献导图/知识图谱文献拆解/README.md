## 本轮最重要的判断

**首先要区分“画出了图”和“建立了可查询的知识图谱”。** 3 篇直接使用实体关系型图谱，1 篇建立民居语义本体，2 篇形成地方性知识分类谱系和图示，1 篇构建形式概念格，另外 17 篇主要是 CiteSpace 文献计量网络。这些成果各有用途，不能将其技术路线相互替代。

**对我们最有用的是三个互补环节。** 汪强等提供从建筑特征图示到规范语汇及关系的思路；陈晓华等展示本体模式转成具体实例和数据库的过程；王笑等与穆潇莹分别提供分析结果组织、组合查询和问题模板的参考。地方性知识文献则提醒我们：可见形态与文化经验需要不同证据渠道，不能因三维模型里看不到就删除，也不能从形态相似直接推出文化因果。

**本批文献尚未给出可以直接套用的“民居语义—实景三维区域”完整方案。** 徽州文将编码叠加模型、复建和生成设计放在研究展望；伏岭村文的智能问答主要是场景讨论。其他核心文献也没有验证我们需要的模型区域标识、跨尺度关联和双向查询。这只限定于本批已读内容，不代表整个研究领域没有相关成果。

由此形成的候选次序是：**明确研究问题 → 定义术语、对象及关系 → 小样本人工编码 → 关联原始证据与三维区域 → 用可核对的问题验证**。这是一组待讨论的试建思路，不是已批准的数据字典、正式样本名单或技术路线。当前研究依据为 [PROJECT_CONTEXT](../../../context/PROJECT_CONTEXT.md)，没有改动论文正文或研究路径图。
