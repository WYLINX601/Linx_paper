一、确定阻断项

1. REPLACE 对新载荷只验证结构外壳，没有在删除前完整验证属性和语义

位置：
  run_graph.py：REPLACE，第一个 WHERE，至第一个 DELETE 之前。
  compile_model.py：validate_payload()、原生属性校验循环。
  run_graph.py：verify_exact()。

已有的事务内保护包括：
  新节点、关系 UID 去重；
  D03 命名空间及 caseId、datasetId；
  sourceModelSha256 字段一致；
  标签、关系类型白名单及新关系端点存在；
  旧节点属性、标签、原生类型和旧关系属性、端点、类型核验。

缺失的是：新属性原生类型约束、必要属性完整性、用途状态一致性、入口参照、通行情境等编译层不变量。sourceModelSha256 字段相同，也不等于这些属性确由该源文件编译产生。

具体反例，均指“对传给 REPLACE 的参数作变更”，不是说冻结模型目前已有这些错误：

  a. 将 E-I01.clearWidthM 从浮点数改为字符串，保留其余身份及 SHA 字段。
     REPLACE 没有检查该属性类型，不能据此在删除前拒绝。

  b. 将 E-C01.useValues 改为重复用途，或删除通行边的 actor。
     标签、端点、命名空间和 SHA 字段仍可全部通过事务内检查。

  c. 只改变新节点的名称或用途值，仍保留原 sourceModelSha256。
     事务没有将整个载荷与冻结源的确定性编译结果绑定。

正常 main() 路径确实先调用 validate_payload()，且写入前再次重编译比对；这显著降低正常调用的风险。问题不是“当前必然写错”，而是“事务自身能拒绝什么”被说得过满。若上述载荷直接进入 REPLACE，事后 verify_exact() 才发现差异时，删除与创建已经提交，不能补回删除前保护。

处理要求：
  正式替换前，要么补齐与明确执行契约相符的事务内新载荷校验和冻结载荷绑定；要么明确采用“受信本地重编译校验＋事务内旧状态及结构校验”的分层契约，不再宣称事务内完整语义验证。若继续以题述的完整事务内验证作为验收条件，本项必须修复。

二、重要建议：当前冻结输入未显示出错，但不能把防御覆盖写得过满

2. 通行只按 contextId 拼接，未校验情境内部一致性

位置：
  compile_model.py：access 循环。
  analyze.py：access 校验与 T04 BFS。

现有代码要求 actor、doorState、obstacleState、observationTime 非空，但 BFS 只比较 contextId。

反例：
  保留 E-walk-1，将 E-G01→E-C02 的 actor 改为另一主体，observationTime 改为另一快照。该边仍可参与原请求的路径。

冻结模型各边的主体和快照一致，因此不是当前路径结果的确定错误。建议至少约束同一 contextId 的主体、快照等情境身份一致；门和障碍描述可按边不同，不必要求所有字段逐字相同。无需扩展成时序网络。

3. 入口参照只核验一侧；另一侧的几何及层位一致性没有被验证

位置：
  compile_model.py：entrances 循环。
  analyze.py：T03。

入口的折线里程算法正确使用了 interpolate，而非弦中点；未知另一侧也没有被补造为通行边。这些处理合理。

但 referenceSpace 之外的另一端，只检查它是 Space，没有检查入口线段是否也落在该空间边界及同一声明层位。

反例：
  将 E-I02.toSpaceId 改为 E-C02，并同步修改相关 access 两端，使端点集合检查通过；入口仍参照前院北边，而后院并不与该线相接。当前编译检查不能凭几何排除这种错接。

冻结模型的连接关系没有显见此问题。建议对“两侧几何均已声明完整”的入口增加一致性核验；未知另一侧继续允许未知，不要求补造空间。

4. 边界参与者和扣洞校验仍有局部缺口

位置：
  compile_model.py：boundaries 循环中的 if b['participantId']。
  analyze.py：T02 的参与者校验及 if b['kind']=='wall'。

反例：
  a. 将已知 building 边的 participantId 置空并移除参与关系，仍可保留实体区间；现有逻辑没有要求该类别必须有参与对象。
  b. building 类边若登记了入口，却把入口区间仍计为实体，扣洞检查只对 wall 执行，不能覆盖该情况。

当前冻结模型的建筑侧没有入口，这属于后续输入防御，不是要求恢复室内构架。建议明确“哪些类别必须有参与者”，并将入口扣除规则施用于所有计入实体长度的边界类别。

5. 来源检查是字段级一致性检查，不是独立的来源真实性验证

位置：
  analyze.py：supported()、rel_supported()。

节点来源检查较细，但 rel_supported() 未核验关系 SHA 与源节点 SHA、analysisRuleUid，也未确认 locator 实际定位到相应字段；列表属性的编译校验还没有检查列表内浮点数是否有限。

冻结运行通过源文件 SHA 和精确回读提供了另一层保护，因此不能据此判定当前结果已污染。建议收紧这些检查，并把“来源一致性”与“独立证据”继续分开。人工设定的来源关系不能成为独立互证。

三、六项模型与 BOT 边界

def validate_payload(payload,path,expected_sha):
    """Compile from frozen source; never trust payload self-declarations."""
    require(hashlib.sha256(Path(path).read_bytes()).hexdigest()==expected_sha,'Source changed since review')
    _,expected,_=compile_model(path)
    require(payload==expected,'Payload differs from exact compiled source')
    require(payload['datasetId']==DS and payload['prefix']==PREFIX,'Wrong namespace')
    for n in payload['nodes']: require(set(n['labels'])<=ALLOWED_LABELS,'Unexpected label')
    for r in payload['relationships']: require(r['type'] in ALLOWED_RELS,'Unexpected relationship')
    return True

    assert cfg and cfg['command'] == '/usr/bin/ssh', 'Configured SSH route required'
    params = StdioServerParameters(command=cfg['command'], args=cfg['args'], cwd=cfg.get('cwd'), env={**os.environ, **cfg.get('env', {})})
    async with stdio_client(params) as (read, write):
        async with ClientSession(read, write, read_timeout_seconds=datetime.timedelta(seconds=120)) as session:
            init = await session.initialize()
            tools = (await session.list_tools()).tools
            save(Path(logdir)/'mcp-tools.json', [t.model_dump(mode='json') for t in tools])
            names = {t.name.replace('-', '_'):t.name for t in tools}
            assert 'read_cypher' in names and 'write_cypher' in names
            async def call(query, params=None, write=False, receipt=None):
                result = await session.call_tool(names['write_cypher' if write else 'read_cypher'], {'query':query, 'params':params or {}}, read_timeout_seconds=datetime.timedelta(seconds=120))
                raw = result.model_dump(mode='json')
                if receipt: save(receipt, {'query':query, 'raw':raw, 'at':datetime.datetime.now().astimezone().isoformat()})
                assert not result.isError, str(raw)
                texts = [x.text for x in result.content if getattr(x,'type',None)=='text']
                value = json.loads('\n'.join(texts)) if texts else result.structuredContent
                while isinstance(value,dict) and 'result' in value:
                    value = value['result']; value = json.loads(value) if isinstance(value,str) else value
                if isinstance(value,dict) and 'error' in value: raise RuntimeError(value['error'])
                return value
            yield call

SNAPSHOT = '''CALL {
 MATCH (n) WITH n ORDER BY coalesce(n.uid,elementId(n))
 RETURN collect({key:coalesce(n.uid,'eid:'+elementId(n)),labels:labels(n),properties:properties(n),types:[k IN keys(n) | {key:k,type:valueType(n[k])}]}) AS nodes
} CALL {
 MATCH (a)-[r]->(b) WITH a,r,b ORDER BY coalesce(r.uid,elementId(r))
 RETURN collect({key:coalesce(r.uid,'eid:'+elementId(r)),source:coalesce(a.uid,'eid:'+elementId(a)),target:coalesce(b.uid,'eid:'+elementId(b)),type:type(r),properties:properties(r),types:[k IN keys(r) | {key:k,type:valueType(r[k])}]}) AS relationships
} RETURN nodes,relationships'''
CONSTRAINTS = 'SHOW CONSTRAINTS YIELD name,type,labelsOrTypes,properties RETURN name,type,labelsOrTypes,properties ORDER BY name'
INDEXES = 'SHOW INDEXES YIELD name,type,labelsOrTypes,properties,state RETURN name,type,labelsOrTypes,properties,state ORDER BY name'

def canonical(graph):
    import copy
    g=copy.deepcopy(graph)
    for category in ('nodes','relationships'):
        g[category].sort(key=lambda r:r['key'])
        for row in g[category]:
            if 'labels' in row: row['labels'].sort()
            row['types'].sort(key=lambda t:t['key'])
    return g

async def snapshot(call, out):
    out=Path(out); out.mkdir(parents=True,exist_ok=True)
    g=canonical((await call(SNAPSHOT,receipt=out/'raw.json'))[0])
    save(out/'graph.json',g)
    constraints=await call(CONSTRAINTS)
    indexes=await call(INDEXES)
    save(out/'schema.json',{'constraints':constraints,'indexes':indexes})
    summary={'nodes':len(g['nodes']),'relationships':len(g['relationships']),'fingerprint':digest(g),'kind':'logical snapshot, not binary dump; restore not rehearsed'}
    save(out/'summary.json',summary)
    return g,summary

async def main():
    import sys
    out=Path(sys.argv[1]); out.mkdir(parents=True,exist_ok=True)
    async with connected(out) as call:
        print('connection',await call("RETURN 'connected' AS status"))
        print('components',await call('CALL dbms.components() YIELD name,versions,edition RETURN name,versions,edition',write=True))
        g,s=await snapshot(call,out/'before')
        assert not any(n['properties'].get('caseId')=='D03V01' or n['key'].startswith('D03V01:') for n in g['nodes']), 'D03 namespace already present: inspect before writing'
        print(json.dumps(s,ensure_ascii=False))
if __name__=='__main__': asyncio.run(main())
