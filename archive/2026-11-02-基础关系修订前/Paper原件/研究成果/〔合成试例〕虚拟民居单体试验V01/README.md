# V01：持续完善的统一原型实例

**D01尺寸和D03外部六项现在共同完善同一个V01原型，而不是三个互不相干的试例。** 当前技术状态：已迁移并完成限定读回核验。[[研究成果/〔合成试例〕虚拟民居单体试验V01/审核视图.html|统一实体关系审核]]为主审核入口；[[研究成果/〔类型图谱〕建筑空间界面与构成关系类型图谱/类型图谱.md|关系模式与原型覆盖]]说明已覆盖和未覆盖的模式。

## 同一对象怎样复用

| 既有身份 | 保留对象 | 本次接续 | 不混同 |
|---|---|---|---|
| V01:B01 | 主屋及原轴网几何 | 宽深、檐口／地坪／脊高程、比较来源 | 不新建D01主屋；轴网尺寸不冒称外墙外包尺寸 |
| V01:S01 | 堂屋 | 在既有空间上补尺寸 | 不是旧D01:S01院落 |
| V01:S05 | 前院 | D01尺寸及D03-T01—T06共同引用 | 不新增另一套前院、不照搬E例用途 |
| V01:S04／S06 | 前廊／院外参照 | 覆盖、入口、通行、局部面积与用途 | 院外参照不自动算作宅院内部 |
| V01:I04／I05 | 廊院分界／院门 | 两侧参与、宿主、位置参照及情境通行 | 不因柱间总跨或开口存在判定净空通过 |
| V01:W08—W10、C01—C04 | 院墙及既有廊柱 | 用关系记录围合参与，按切片重算 | 不以顶盖代实体，不恢复内部构架分析 |

新增U01只组织既有主屋、前院、院墙及确有需要的侧房；B02沿用旧D01侧房的明确合成参数，并声明采用共同坐标是本次人工设计，不是实测配准。DATUM01、CMP01与规则有独立追溯用途，普通尺寸不再另建输入节点。EV01保留用户指定名称“示例素材”，EV09保留旧D01来源的独立身份。

## 当前可以查看与计算

- **D01最小链：** 8个既有／明确新增对象上的尺寸和来源；侧房减主屋檐口高程差约3.733333m，不能沿用旧例2m。自身高度另减各自地坪。
- **D03六项当前外部范围：** 空间边界、围合、入口、局部通行、位置面积、有据用途，均接续相同S04/S05/S06与I04/I05。
- **围合：** S05在z=1m切片声明周长28.08m、扣洞并计柱截面的净实体线长17.72m；是限定线长描述，不是三维围合度或风貌优劣评分。
- **面积：** 仅在0m层115.20m²指定局部窗口计算，排除S06与3m侧房，不报告全宅比例。
- **原拓扑：** 保留墙轴交接、墙柱简化包络相交、坡面共边及来源；原遮蔽试验没有因此重新执行。

## 类型与实例各自维护什么

案例JSON维护这个原型的对象、几何、属性和关系；优化基准U15维护共同规则；类型图谱维护模式及覆盖；D01／D03详细拆解表维护分析问题、数据与判据。页面和Neo4j是派生投影，不反向成为第二份手工主源。

旧D01／D03的同名对象只作“角色与表达能力接续”，不标sameAs。A—E中双院、单向路径、明确开放／未知和多用途变体保留为归档测试，不把互斥布局拼进同一物理宅院。旧入口转为转接／历史入口，不再维护活动实例参数。

## 更新与验证边界

以后某空间需要新增尺寸或用途，先定位现有UID，在该对象及明确字段来源上补充；仅有新独立对象证据时新增节点。几何、参照或来源版本变化时，先检查受影响分析并重算或明确失效，再重新核验；当前程序是固定原型的显式编译／验证流程，不是任意模型通用规则引擎或自动同步服务。

内部构架仍暂停；既有室内对象、支承断言保留历史身份，不作为本轮新增分析。D01-T03/T04和完整T06未完成；D04／D05未实例化；时序、感知、真实样本与跨地区泛化均未验证。合成过程材料不进入正文，也不默认进入附录。

原[V01图纸与几何浏览快照](../../archive/2026-10-30-统一原型合并前/原件/v01-old.html)及旧决策仍可追溯，但当前实体关系审核以本页入口为准。技术执行、独立审查、页面检查与用户语义审核分别在[核验说明](Neo4j/README.md)记录。
