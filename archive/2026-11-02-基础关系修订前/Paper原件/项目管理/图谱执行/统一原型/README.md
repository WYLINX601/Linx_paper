# 统一原型执行入口

活动源是[[研究成果/〔合成试例〕虚拟民居单体试验V01/案例模型.json]]，数据库与页面是其派生投影。工具只服务已声明的固定合成原型，不是自动同步服务或任意图谱的通用规则引擎。

## 已验证入口

使用academic Python执行本目录`check.py`：默认下载当前主源与限定归档到academic scratch，运行50项统一检查和10项旧D03回归，不连接数据库、不写Paper。加`--database`才通过现有SSH-backed MCP进行只读逐记录与13组功能查询验证，并在scratch生成新的审核页候选；仍不发布或导入。当前模型不符或版本变化会明确停止，不重置基线。

`tools/compile_model.py`负责固定模型校验与编译；`analyze.py`从读回记录计算；`queries.py`维护只读查询；`build_review.py`仅从精确匹配的已验证读回制作正式离线页。`run_graph.py`保留本次受限迁移实现，但正常维护不直接调用write；已有execution-stage禁止重发。后续新版本须另行冻结、审查与授权，不用本次token自行写库。

[数据库与证据](../../../研究成果/〔合成试例〕虚拟民居单体试验V01/Neo4j/README.md)；[旧D03变体](../../../archive/2026-10-30-统一原型合并前/README.md)。`审查冻结/`仅保留独立复审当时五个核心模块，清单列出的其他冻结输入见案例原件／迁移数据；清单不代表本目录包含所有输入。主会话最后的排序／只读验证升级差异与SHA保留于数据库核验。

不要直接在Paper内运行会生成输出的底层脚本；`check.py`为经scratch隔离的入口。正式发布须最新SHA、mac-paper备份和回读；未提供自动回滚或无提示同步。
