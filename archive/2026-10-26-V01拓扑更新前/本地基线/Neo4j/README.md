## 先看这些内容

2026-10-24已在用户现用Chrome的Neo4j Browser中，将以下5条查询保存到Queries → Drafts，名称为V01-01至V01-05。刷新后逐条回读内容一致，并实际运行V01-03，返回5个空间节点、4条通行关系。[保存与运行截图](Queries收藏已保存.jpg)。这是该Chrome浏览器中的保存状态，其他浏览器需另行保存。

建筑、空间、构件、界面之间的关系（先隐藏证据连线，便于理解）：

```cypher
MATCH (a:V01)-[r]->(b:V01)
WHERE type(r) <> 'DOCUMENTS'
RETURN a, r, b;
```

空间通行骨架：

```cypher
MATCH (a:V01:Space)-[r:DIRECT_ACCESS_TO]->(b:V01:Space)
RETURN a, r, b;
```

这类边只存一条，并有 `bidirectional=true`；图上箭头是存储方向。查路径时显式使用无向匹配，并核查双向条件：

```cypher
MATCH p=shortestPath((a:V01:Space {id:'S06'})-[:DIRECT_ACCESS_TO*]-(b:V01:Space {id:'S03'}))
WHERE all(r IN relationships(p) WHERE r.bidirectional=true)
RETURN p;
```

已核实路径为南侧外部参照区→前院→前廊→堂屋→东室，共4次跨空间通行。此结果不等于空间句法整合度。

材料标签分组：

```cypher
MATCH (n:V01:Element)
UNWIND [l IN labels(n) WHERE l STARTS WITH '材质_'] AS material
RETURN material, n.name AS object, n.id AS id
ORDER BY material, id;
```

同一屋顶同时有木、陶瓦标签。标签计数不等于材料面积或体积占比。墙芯材料在完整合成设定中有答案，不代表遮蔽图纸足以推出这一答案。

查看一面墙的证据及适用范围：

```cypher
MATCH (e:V01:Evidence)-[r:DOCUMENTS]->(w:V01:Wall {id:'W06'})
RETURN e.name AS evidence, r.scope AS scope, w.name AS object;
```
