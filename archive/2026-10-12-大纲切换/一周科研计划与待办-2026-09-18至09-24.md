# 一周科研计划与待办：2026年9月18日—9月24日

> 本周目标：在导师下一次汇报前，回答“研究对象是否可获得、相对前人研究补什么、方法能否跑通、接下来需要多少工作量”。形成一套可检查的可行性材料，而非一周完成正式调查或得出论文结论。
>
> 方向依据见[[archive/2026-10-12-大纲切换/科研方案-导师反馈调整版]]，章节安排见[[archive/2026-10-12-大纲切换/论文大纲-特征提取与图谱构建]]。以下勾选项均为待执行科研任务，文档写好不代表这些任务已经完成。

## 一、时间假设与本周交付

按当前日期2026年9月18日启动，9月24日前后汇报；会议时间尚未预约。每天安排3—5小时专注工作，总计约30小时。若实际投入明显少于这一假设，优先保住对象、文献差异和一个真实流程样例，削减三维展示及排版工作。

### 1.1 本周结束交付材料

| 编号 | 交付物 | 最低完成标准 |
| --- | --- | --- |
| W1 | 研究对象与边界说明 | 一页说明研究谁、哪些不纳入、证据从哪里来、仍有哪些未知 |
| W2 | 候选样本清单与分布草图 | 每条有来源与核实状态；可调查对象与仅有文献记录的对象分开 |
| W3 | 对象／方法文献对照表 | 至少核读1篇直接对象研究和1篇可迁移方法研究，另列必要补充项 |
| W4 | 试验资料包 | 一份人工参考、一条辅助处理或数字采集试验记录、一页带来源的图谱样张 |
| W5 | 可行性判断与后续预算 | 明确继续、缩小范围或调整路径，列出工时依据及下阶段安排 |
| W6 | 下次汇报提纲 | 约6页信息内容，突出证据、试验、问题及需要导师判断的事项 |

文献原文确实无法获得时，W3应标“未完成原文核验”，不能以阅读笔记冒充。没有适用数据时，W4可提交基础流程样例和明确的采集缺口，但结论只能是“技术或对象可行性待验证”。

### 1.2 优先顺序

**P0必须完成：** 核查对象可得性、直接对象文献与方法文献、形成一个证据清楚的处理样例、输出可行性判断。

**P1条件允许完成：** AI辅助分割小试、同对象多视角重建试验、独立复核。

**P2本周不排入：** 正式LoRA训练、多模型竞赛、完整辅助设计案例、精细三维打印、复杂知识平台搭建。

## 三、每日具体待办

### Day 1｜9月18日：收敛问题，核对已有研究

**一句话目标：** 用一页纸说清研究边界，并查明已有对象研究与你的关系。

- [ ] 用[[archive/2026-10-12-大纲切换/科研方案-导师反馈调整版#1.3 研究问题]]为底稿，整理W1：对象、总问题、主要成果和不包含的任务。
- [ ] 定位赵潇诺《景宁畲族传统民居营造技艺研究》原文，核准作者、年份、目录和样本范围；已有笔记中的年份矛盾要记录。
- [ ] 优先核读其研究方法、类型分析、图表与结论，记录实际页码，不必按页从头通读。
- [ ] 写出“前人已完成／我可能补充／目前没有证据”的三列对照，至少各有具体内容或明确空缺。
- [ ] 列出1—2篇补充对象文献的检索线索；找不到时保留检索记录，不制造第二篇“已精读论文”。

**验收：** 能回答“如果不用AI，这项研究相对现有研究还准备新增什么”；答不出时将其列为首要风险。

**时间分配：** 方向整理约1小时，原文定位与重点核读约2小时，对照记录约1小时。

### Day 2｜9月19日：核查候选对象与数据条件

**一句话目标：** 找到能够支撑研究的对象线索和第一批可使用资料。

- [ ] 从地方政府及主管机构公布的相关名录、地方资料和论文附录查找候选村落与建筑，保存页面或文件来源、日期和定位信息。
- [ ] 区分“村落数量”和“具体建筑数量”，建立候选清单；前者不能代替建筑样本数。
- [ ] 将候选对象标为“文献记录／名录在册／已核实现存／可进入／待联系”，没有证据的栏位留空。
- [ ] 形成分布草图与1—2个优先踏勘片区，并说明选择理由和可能的代表性偏差。
- [ ] 盘点现有照片、图纸和设备，检查是否已有同一建筑的多视角资料；记录来源、使用条件与缺失部位。
- [ ] 如需联系当地人员或机构，列出联系对象和具体问题，由本人安排联系；本计划不代表已联系或已获进入许可。

**验收：** W2能够区分“知道有这个建筑”和“能够拿到研究资料”。本日可以形成未知项清单，无须虚填全县遗存总量。

**数据不足的替代任务：** 有合法使用条件的公开或既有资料可用于操作演示，并明确与正式自采样本分开；没有同对象多视角资料时，不启动三维重建。

### Day 3｜9月20日：迁移方法，形成采集与编码规则

**一句话目标：** 确定一条可执行路线，以及每项特征需要怎样的证据。

- [ ] 核读至少1篇图谱或类型提取方法原文，优先从李世芬等研究线索入手，补齐页码、图号与具体步骤。
- [ ] 将其拆成“研究输入—分类依据—处理步骤—输出—验证”，注明可迁移和不可迁移部分。
- [ ] 从旧词表选出约5—8项可观察字段，拟定调查编码表；每项均有定义、证据、未知状态，不预填地方性阈值。
- [ ] 拟定建筑采集卡：身份与位置、各面与细部资料、尺寸参照、历史和改造、可观察条件。
- [ ] 确定本周只试1个AI任务，优先构件区域辅助分割；写清输入、输出和如何判定可用。
- [ ] 锁定一个现成工具或已有可用环境的试验方案，核对数据、导出能力、硬件和使用成本；本周不给基础模型训练排期。

**验收：** 任取一个字段，都能回答“去现场采什么、怎样获得取值、什么情况下记未知”。

### Day 4｜9月21日：先做人工参照，再跑小样本

**一句话目标：** 得到一份真实的原始资料到特征记录的处理样例。

- [ ] 从来源清楚的资料中选择1—3栋建筑的约10—20张图像作为预试范围；这是操作预算，不是正式样本量要求。
- [ ] 选定一个目标部位，按编码规则建立人工参照，并标注遮挡、模糊和争议边界。
- [ ] 保存纯人工处理过程与耗时，然后执行所选辅助分割任务，保留原始输出、人工修正及版本参数。
- [ ] 如有合格的同对象多视角资料和可用环境，对1栋建筑试做重建；没有条件则改为记录现场试采需求。
- [ ] 完成至少1张建筑采集卡及对应特征记录，建立建筑编号—原图—处理结果之间的对应关系。

**验收：** 有可打开的输入、结果与记录，能够解释哪部分由人完成、哪部分由工具完成。不能以工具介绍或演示视频代替自己的试验。

**时间保护：** 环境问题连续占用约2小时仍无可运行结果时，记录原因，转到人工样例和可用现成环境的评估。单独列出AI未跑通的风险，不继续挤占全部研究时间。

### Day 5｜9月22日：检查质量，生成一页图谱样张

**一句话目标：** 判断资料处理是否有用，并确定最终成果应该长什么样。

- [ ] 比较人工参照、AI未修正输出与人工修正后结果；记录错误类型、交并比或适用的质量描述。
- [ ] 汇总全部耗时，计入提示、等待、修正和核验；说明重复处理同图的熟悉效应。
- [ ] 邀请可获得的建筑学背景同学复核少量关键判断；没有复核人时明确标为单人预试，不宣称专家一致性。
- [ ] 用真实可用资料制作一页“建筑编号—构件图例—可观察特征—证据来源”的图谱样张。
- [ ] 若存在多栋资料，再展示一个初步类型对照；不得用单栋建筑推导稳定类型或全域频次。
- [ ] 写出三条结论：什么可行、什么尚未验证、什么需要调整。工具失败也应保留记录。

**验收：** 图谱中每个图例和数值都能回到资料，原始记录与研究判断分开；样张标注“预试，非正式研究结论”。

### Day 6｜9月23日：估算正式工作量，确定下一阶段

**一句话目标：** 把试验结果转化为可以承担的研究范围。

- [ ] 按试验记录估算单栋采集、整理、编码、建模与制图的人工耗时，机器运行时间另列。
- [ ] 结合候选清单提出正式采样范围与选择规则；数量暂写为建议预算，并说明未核实部分。
- [ ] 区分“基础档案覆盖”和“典型建筑深度建模”，判断是否有必要每栋均做三维。
- [ ] 将后续日期、数据条件、设备与必要费用写入W5，不预订差旅或付费服务。
- [ ] 根据[[archive/2026-10-12-大纲切换/科研方案-导师反馈调整版#七、可行性判断与备选处理]]选择继续、缩小范围或调整路径，并写出理由。
- [ ] 对照新版论文大纲，确认每个核心章节都有明确的计划证据与输出，不保留空泛技术章节。

**验收：** 能回答“下一次出发采什么、预计处理多久、失败后如何调整”，而不仅是“继续读文献”。

### Day 7｜9月24日：形成导师汇报材料

**一句话目标：** 用证据汇报可行性，请导师判断仍影响研究推进的关键选择。

- [ ] 整合W1—W5，每项标注完成、部分完成或待验证，并提供实际材料位置。
- [ ] 按下一节的6页提纲整理汇报内容，优先放对象证据和自己的试验结果。
- [ ] 准备3项待讨论：研究范围是否合适、相对前人的增量是否成立、采集与AI路径是否值得继续。
- [ ] 在可行性材料清楚后，提出是否需要导师协助联系文化遗产方向老师，不将此视为已安排合作。
- [ ] 完成约10分钟口头汇报演练，能够解释样本、资料、方法和成果之间的关系。
- [ ] 如当天有汇报，记录导师最终判断；若尚未约到时间，先形成可发送的材料包，会议状态保持未完成。

**验收：** 导师能够据此决定下一阶段范围与路径，无需靠想象判断“AI也许能做什么”。

## 六、一周结束时的判断

### 6.1 可以继续

- [ ] 有明确范围和可获取的研究对象，主要采集条件已得到证据支持。
- [ ] 核验了直接对象研究，拟增加的工作具有具体依据。
- [ ] 至少一条资料到特征再到图谱样张的流程有真实产物。
- [ ] 后续工作量与时间预算相容，关键不确定性有补查安排。

### 6.2 限定范围后继续

如果对象资料成立，但三维覆盖、AI质量或单栋成本不理想，收窄地域、类型或技术任务；同步修改题目、指标和结论边界。具体理由记录在下方。

### 6.3 需要调整对象或方法

如果无法建立可获取样本、前人已经充分解决目标问题，或关键指标始终没有可用数据依据，带着已查证材料尽快讨论调整。不能单靠增加模型、加长题目或扩充理论框架消除这些问题。

- 已完成材料位置：待填写。

- 导师反馈与确认日期：待填写。
