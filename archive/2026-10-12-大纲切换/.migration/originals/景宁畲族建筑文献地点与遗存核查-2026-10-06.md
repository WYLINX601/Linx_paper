# 景宁畲族建筑文献地点与遗存核查

## 本轮任务与边界

依据2026年10月6日本次讨论，先核查 Zotero「建筑风貌 → 畲族」分类中的现有文献资料，汇总地点、建筑、数量与保存情况。由用户在证据整理完成后判断研究价值、限定地域范围和确定研究对象。本轮不预先按传统性、民族唯一性、保存完好度或进入条件筛除对象。

文献核查全集为 collection `2UDM8WX7` 中23条记录；书目清单见[[01_sources/2026-10-06-Zotero畲族分类文献清单快照]]。原始PDF保留在 Zotero，汇总材料通过条目key与本地PDF链接定位，未修改 Zotero。

23条书目均完成第一轮筛查。其中22条有PDF附件，21条可读取目标论文正文；竹里村微更新论文（L06）没有PDF，只能保留摘要线索；城市风貌规划论文（L19）的附件仅有1页首页／摘要，不能据此判断全文中是否有建筑清单。长篇论文采用全文检索、相关章节核读与关键数量页目视复核，未逐页穷尽全部图像。各篇阅读状态和缺口在证据表中单列。

目录中还有5篇以宁德、广东双田、桐庐峩山、武义柳城、泰顺竹里为主要对象的资料。它们及其他论文中的县外比较案例均保留地域和用途标记，避免误计为景宁遗存。

## 数量与状态的记录规则

1. 分开记录村落、住户、建筑单体、院落、建筑群、构件、侧样、问卷和人口，不能直接互换。
2. 「某村有10幢清代建筑」与「作者实测10幢」属于不同口径；数量须同时记录统计对象、范围与来源页。
3. 文献中的「现存」是作者所记录时点的状态，出版年份不能自动当作调查日期。本轮未进行2026年逐栋现状确认。
4. 文献未说明数量、调查日期或身份依据时，保留未知。搬迁不能直接等同拆除；修缮、改造、重建分别记录。
5. 同一名称在不同文献中出现时先关联证据；名称相似、行政村与自然村、旧村与新村及房主更替需要另核，不据名称强行合并。
6. 外地区、比较建筑、现代设计、拟建方案和已消失对象均保留并标明角色。是否纳入研究由用户后续决定。

### 审核发现与尚缺的证据

1. **文献已有可追踪对象，但尚无去重后的现存总量。** 东弄提供村级数量和编号图表，是后续逐栋核实的明确入口；大张坑和桃源提供总量线索，但还需补齐身份清单。其他村落多为“保存较好”“数量较少”等定性描述，不能据此赋予栋数。
2. **保存状态应按时点并列。** 同一建筑在较早论文中荒废、较晚论文中修缮或改用并不一定矛盾。没有确切调查日的材料按“作者记录时点，日期未明”处理，不直接按书目年份更新现状。
3. **书目日期与论文封面日期存在差异。** 例如L08封面提交2022年、Zotero为2023年；L09封面提交2015年、Zotero为2016年；L12封面2024年、Zotero为2025年；L14封面提交2022年、Zotero为2023年。分别保留，未据此改动Zotero。
4. **数量不能相加。** 107／73／16属于东弄同组总体与子类；52项编号和52座质量样本可能重叠；户数、侧样数、文化设施数、人口与建筑编号不能换算为独立住宅数。本文不输出县域建筑总数。
5. **民族关联仍需证据。** “畲族村内建筑”“畲族家庭居住”“传统畲族营造体系”“现代设计采用畲族元素”是不同信息。本轮按原文记录，不以村名或装饰代替身份核验。

## 与当前论文工作的衔接

本轮为[[科研方案-导师反馈调整版]]和[[论文大纲-特征提取与图谱构建]]提供对象线索。后续顺序为：文献地点与建筑线索 → 去重及2026现状核实 → 用户限定研究范围、确定对象 → 试采与工作量评估 → 正式特征总结与图谱方法确定。

文献记载对象数、当年作者调查数、2026已核实现存数和最终有效样本数，应分别统计。本轮完成文献提取后仍不能宣称「景宁现存畲族传统民居共多少栋」或「样本已经足以支撑论文」。


## 下一轮：由候选线索形成可核实的对象清单

建议先审阅上述数量表及证据表，标记“继续核查／暂缓／作为背景”，再确定联系和实地核查范围。每个拟继续核查的对象建一行，至少补以下字段：

| 核查字段 | 要回答的问题 |
| --- | --- |
| 对象身份 | 原文名称、编号、村落范围、现址或定位点能否对应同一栋？重复文献是否描述同一对象？ |
| 当前状态 | 核实日期是什么？完整现存、部分遗存、拆除、重建还是尚未确认？ |
| 历史与民族关联 | 年代、户主／使用群体、营造与传承依据来自什么材料？ |
| 资料与采集条件 | 有无历史照片、平面、侧样、测绘？现场能否接近，能否记录论文所需特征？ |
| 用户判断 | 是否纳入主样本、比较样本或背景；依据是什么？ |

待你明确研究范围后，再统计该范围内“文献对象数—去重候选数—已核实现存数—可采集数—有效样本数”。是否足以支撑论文，要结合形态差异覆盖、资料完整程度和试采工时判断，不能只依赖一个栋数门槛。

## 对特征总结的预留框架

对象确定后，围绕暂定题目《景宁畲族传统民居风貌特征提取与图谱构建研究》，以每栋建筑为记录单位，而非先写一个统一的“畲族建筑特征清单”。先比较：体量与层数、平面与空间、屋顶和山墙、立面与门窗、材料与构造、装饰，以及保存与改造。文化和族群信息用于解释，分别注明证据。

每项特征至少保留“字段定义—建筑编号—取值／观察描述—照片或图纸—来源与日期—未知原因”。内部平面和木构侧样仅在有图纸或可观察证据时记录。汇总时再区分样本中的共性、类型差异、同村变体和改造影响，并将结果对应到实例；缺少对照研究时不写成“畲族独有”。这一框架暂不作为筛选条件，待研究对象确定后细化。
