# 文献库

用一篇文献一份 Markdown 的方式，保存研究问题、框架、关键证据和可参考之处。框架适用于不同学科与研究主题，便于后续选文献、对照研究、论证方法和准备汇报时优先调用提炼笔记。

## 通用笔记框架

1. **文献信息与阅读范围**：准确识别文献、原文入口，以及实际核读的章节或页码。
2. **一句话概括**：作者针对什么问题，用什么思路，形成什么主要成果。
3. **研究问题与框架**：整理问题、研究对象或材料、关键概念、方法／论证步骤及其衔接。
4. **关键成果与证据**：提炼主要结论、方法或图表，保留原文定位及作者给出的支持。
5. **可参考之处**：由笔记者说明可复用的思路、方法、材料或表达方式，以及使用条件。
6. **局限与待核内容**：区分作者声明的局限、笔记者判断、未读或未核的信息。
7. **关联文献与项目应用（可选）**：记录对照文献或具体项目的使用位置。通用提炼主体不依赖项目章节。

复制[文献提炼模板](文献提炼模板.md)，将填写后的笔记保存到本目录，文件名建议为“作者-年份-短标题.md”。按原文实际内容调整小节：理论研究保留论证链，综述保留分类与综合框架，实证研究保留数据及验证过程，不强行套用实验流程。

## 整理与调用方式

- 先确认文献身份和原文入口；同一文献以 DOI、Zotero 条目或已核准书目信息识别，补读时更新已有笔记。
- 按模板提炼实际核读内容，重点保留研究逻辑及可参考之处。原文已有保存位置时直接链接，图表按实际需要引用或裁切，并注明来源与图号。
- 作者的内容与笔记者的启发分别记录；局部阅读标明范围，不用摘要推定全文方法或研究效果。
- 后续查阅优先使用索引和提炼笔记。精确引文、关键数字或笔记未覆盖的细节通过已保留定位回查原文，核查后补进笔记。

通过一篇笔记应能回答：作者做了什么、怎样展开、依据是什么、哪里可参考、适用于什么条件、证据在哪里。笔记以精简为原则，详细摘录和大量图片可另设附件并链接。
