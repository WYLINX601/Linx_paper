## 类型与实例各自维护什么

案例JSON维护这个原型的对象、几何、属性和关系；优化基准U15／U16维护共同规则；类型图谱维护模式及覆盖；D01／D03—D06详细拆解表维护分析问题、数据与判据。页面和Neo4j是派生投影，不反向成为第二份手工主源。

旧D01／D03的同名对象只作“角色与表达能力接续”，不标sameAs。A—E中双院、单向路径、明确开放／未知和多用途变体保留为归档测试，不把互斥布局拼进同一物理宅院。旧入口转为转接／历史入口，不再维护活动实例参数。

## 更新与验证边界

以后某空间需要新增尺寸或用途，先定位现有UID，在该对象及明确字段来源上补充；仅有新独立对象证据时新增节点。几何、参照或来源版本变化时，先检查受影响分析并重算或明确失效，再重新核验；当前程序是固定原型的显式编译／验证流程，不是任意模型通用规则引擎或自动同步服务。

内部构架仍暂停；既有室内对象、支承断言保留历史身份，不作为本轮新增分析。D01-T03/T04和完整T06未完成；D04／D05／D06仅完成本页所列合成范围，非全部子项或真实应用；时序、感知、真实样本与跨地区泛化均未验证。合成过程材料不进入正文，也不默认进入附录。

原[V01图纸与几何浏览快照](../../archive/2026-10-30-统一原型合并前/原件/v01-old.html)及旧决策仍可追溯，但当前实体关系审核以本页入口为准。技术执行、独立审查、页面检查与用户语义审核分别在[核验说明](Neo4j/README.md)记录。
