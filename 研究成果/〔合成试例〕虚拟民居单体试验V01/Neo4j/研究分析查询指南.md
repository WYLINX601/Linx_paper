# 研究分析查询指南：Graph 与 Table 双视图

## 快速入口

- **看对象与关系图：**[Graph 查询文件](研究分析查询-Graph.cypher)。
- **看数值、比例、计数和来源字段：**[Table 查询文件](研究分析查询-Table.cypher)。
- [本次查询核验与返回类型](研究分析查询核验.json) · [数据库主入口](README.md) · [唯一案例主源](../案例模型.json)。
- 关联主题：[图谱试建、查询与有效性](../../../主题研究/〔检验与评价〕图谱试建、查询与有效性/〔检验与评价〕图谱试建、查询与有效性.md)。

**使用方法：每次复制一个编号下的一组查询执行，不要一次粘贴整个文件。** C01—C22是本指南索引，不替换原Q01—Q26审核编号。所有查询只读；没有为可视化新建节点、关系或类型。案例JSON、双基准和原审核查询继续各自单源维护，本指南只是有明确版本依赖的查询用法层。

## 为什么上一版不是Graph？

上一版为分析审阅主要返回 `n.uid`、数值、计数、字符串列表及JSON字符串。这些是标量／列表投影，不是原生节点、关系或路径。即使MATCH沿图遍历，RETURN只留下编号，结果仍是分析表，不能靠切换视图把编号还原成图。

另外，聊天中的MCP工具以JSON传输查询结果，不会自动生成Neo4j Browser的Graph窗口。本轮已经用valueType核对原生返回类型，但聊天中的JSON外观不代表数据库返回的都是字符串。本Obsidian笔记提供可复制查询，不直接连接或执行Neo4j。

| RETURN内容 | 返回性质 | 推荐查看 |
|---|---|---|
| `n.uid`、`n.widthM`、`count(n)` | 字符串／数值／统计量 | Table |
| `[n IN nodes(p) | n.uid]` | 编号列表，不是原生PATH | Table |
| `n` | 原生NODE | Graph查看节点，Table查看属性 |
| `a,r,b` | 节点与实际关系 | Graph |
| `p` | 原生PATH，包含节点与关系 | Graph |

在Neo4j Browser运行Graph版后，选择结果帧左侧的Graph视图。混合返回中的数值／candidate仍可切到Table查看；这些标量不会自动成为图中的新节点。若只看到编号或JSON，请先检查实际RETURN，而不是修改数据库。

浏览器可能启用“Connect result nodes”自动补显已返回节点间的其它既有关系。若要严格审阅本次查询明确返回的边，应关闭此显示选项；这不是数据库写入。本指南没有更改用户的Browser配置。

## 必须保留的边界

- 当前仍是V01合成原型，不是景宁真实样本结论。Graph能显示不等于几何计算、完整语义或有效性已经验证。
- Graph用于核对“谁与谁有什么关系”；Table用于核对“多少、为何、来源、版本及缺失”。两者互补，不能互相替代。
- C02、C10、C13的Graph会显示来源／基准／归属等实际背景；尺寸、用途、材料仍按现有属性／标签方案维护，不为画图另造实体。
- C20、C22没有返回直接关系，只显示待计算对象节点。当前几何派生关系尚未持久化，不能为了连线虚构覆盖、包含或通行。请关闭自动补边后审阅明确返回内容。
- Graph展开来源、开口或路径后，返回行数可能与Table不同；行数不等于独立对象数或样本数。
- 内部构架继续暂停，D07暂缓、D08不纳入；不因增加Graph视图恢复这些分支。

## 逐项查询

### C01 对象层级、构件成员与平面参照

**模块：** 共同骨架。**分析边界：** 区域包含、构件成员、几何面归属和相对位置分开返回，不把成员关系说成三维包含。

**Graph版：** 图中呈现实际登记的组织与位置关系，不把成员归属升格为三维包含。

```cypher
MATCH (a:V01)-[r]->(b:V01)
WHERE type(r) IN ['BOT_HAS_SPACE','BOT_HAS_BUILDING','MEMBER_OF_ZONE','PART_OF','PLAN_POSITION']
RETURN a AS anchor,r AS relation,b AS neighbor,null AS path;
```

**Table版：** 关系检索。

```cypher
MATCH (a:V01)-[r]->(b:V01) WHERE type(r) IN ['BOT_HAS_SPACE','BOT_HAS_BUILDING','MEMBER_OF_ZONE','PART_OF','PLAN_POSITION'] RETURN a.uid AS source,b.uid AS target,type(r) AS type,r.role AS role,r.scope AS scope ORDER BY type,source,target;
```

### C02 面宽、进深、自身檐高和比例

**模块：** D01-T01/T02。**分析边界：** 沿用各对象自己的量测边界；空值保持未知。不同对象的轴网与外包口径不能无条件混比。

**Graph版：** 显示量测对象及来源／基准背景；比例和自身檐高仍从Table版读取，不为普通尺寸另造节点。

```cypher
MATCH (n:V01)
WHERE n.uid IN ['V01:B01','V01:B02','V01:S01','V01:S02','V01:S03','V01:S04','V01:S05','V01:S06']
OPTIONAL MATCH (n)-[r:HAS_SOURCE|USES_DATUM]->(ref:V01)
RETURN n AS anchor,r AS relation,ref,null AS path;
```

**Table版：** 直接计算。

```cypher
MATCH (n:V01) WHERE n.uid IN ["V01:B01", "V01:B02", "V01:S01", "V01:S02", "V01:S03", "V01:S04", "V01:S05", "V01:S06"] RETURN n.uid AS uid,n.widthM AS widthM,n.depthM AS depthM,n.groundZM AS groundZM,n.eaveZM AS eaveZM,n.eaveZM-n.groundZM AS ownEaveHeightM,CASE WHEN n.depthM>0 THEN n.widthM/n.depthM ELSE null END AS widthDepthRatio,CASE WHEN n.widthM>0 THEN (n.eaveZM-n.groundZM)/n.widthM ELSE null END AS ownEaveHeightWidthRatio,n.measurementBoundaryBasis AS basis ORDER BY uid;
```

### C03 侧房减主屋的共同基准檐口高差

**模块：** D01-T05。**分析边界：** 核对来源支持字段、单位、共同基准、情境和版本；valid=false时拒绝计算。自身檐高与共同基准高差不同。

**Graph版：** 保留Table版的来源／基准／版本资格检查，显示比较结果节点及实际角色关系，不增HIGHER_THAN边。

```cypher
MATCH (c:V01 {uid:'V01:CMP01'})
OPTIONAL MATCH (c)-[ar:COMPARES_SUBJECT]->(a)
OPTIONAL MATCH (c)-[br:COMPARES_REFERENCE]->(b)
OPTIONAL MATCH (a)-[sa:HAS_SOURCE]->(asrc) WHERE sa.id=ar.sourceRelationId AND 'eaveZM' IN sa.fields
OPTIONAL MATCH (b)-[sb:HAS_SOURCE]->(bsrc) WHERE sb.id=br.sourceRelationId AND 'eaveZM' IN sb.fields
OPTIONAL MATCH (a)-[da:USES_DATUM]->(ad) WHERE 'eaveZM' IN da.fields
OPTIONAL MATCH (b)-[db:USES_DATUM]->(bd) WHERE 'eaveZM' IN db.fields
WITH c,a,b,ar,br,sa,sb,asrc,bsrc,da,db,ad,bd,coalesce(a.unit='m' AND b.unit='m' AND a.geometryActive=true AND b.geometryActive=true AND ad=bd AND da.frameVersion="V01-unified-2.2" AND db.frameVersion="V01-unified-2.2" AND a.scenario=b.scenario AND c.scenario=a.scenario AND a.geometryVersion="V01-unified-2.2" AND b.geometryVersion="V01-unified-2.2" AND ar.geometryVersion=a.geometryVersion AND br.geometryVersion=b.geometryVersion AND c.inputGeometryVersion=ar.geometryVersion AND c.inputGeometryVersion=br.geometryVersion AND ar.expectedSourceVersion=sa.sourceVersion AND ar.expectedSourceVersion=asrc.sourceVersion AND br.expectedSourceVersion=sb.sourceVersion AND br.expectedSourceVersion=bsrc.sourceVersion AND a.eaveZM IS NOT NULL AND b.eaveZM IS NOT NULL,false) AS valid
RETURN c AS anchor,ar AS relation,a,br,b,sa,asrc,sb,bsrc,da,ad,db,bd,
       null AS path,valid,
       CASE WHEN valid THEN a.eaveZM-b.eaveZM ELSE null END AS valueM,
       CASE WHEN valid THEN abs(c.valueM-(a.eaveZM-b.eaveZM))<1e-9 ELSE false END AS cacheAgreement;
```

**Table版：** 带资格检查的直接计算。

```cypher
MATCH (c:V01 {uid:'V01:CMP01'})
OPTIONAL MATCH (c)-[ar:COMPARES_SUBJECT]->(a)
OPTIONAL MATCH (c)-[br:COMPARES_REFERENCE]->(b)
OPTIONAL MATCH (a)-[sa:HAS_SOURCE]->(asrc) WHERE sa.id=ar.sourceRelationId AND 'eaveZM' IN sa.fields
OPTIONAL MATCH (b)-[sb:HAS_SOURCE]->(bsrc) WHERE sb.id=br.sourceRelationId AND 'eaveZM' IN sb.fields
OPTIONAL MATCH (a)-[da:USES_DATUM]->(ad) WHERE 'eaveZM' IN da.fields
OPTIONAL MATCH (b)-[db:USES_DATUM]->(bd) WHERE 'eaveZM' IN db.fields
WITH c,a,b,coalesce(a.unit='m' AND b.unit='m' AND a.geometryActive=true AND b.geometryActive=true AND ad=bd AND da.frameVersion="V01-unified-2.2" AND db.frameVersion="V01-unified-2.2" AND a.scenario=b.scenario AND c.scenario=a.scenario AND a.geometryVersion="V01-unified-2.2" AND b.geometryVersion="V01-unified-2.2" AND ar.geometryVersion=a.geometryVersion AND br.geometryVersion=b.geometryVersion AND c.inputGeometryVersion=ar.geometryVersion AND c.inputGeometryVersion=br.geometryVersion AND ar.expectedSourceVersion=sa.sourceVersion AND ar.expectedSourceVersion=asrc.sourceVersion AND br.expectedSourceVersion=sb.sourceVersion AND br.expectedSourceVersion=bsrc.sourceVersion AND a.eaveZM IS NOT NULL AND b.eaveZM IS NOT NULL,false) AS valid
RETURN c.uid AS uid,a.uid AS subject,b.uid AS reference,valid,CASE WHEN valid THEN a.eaveZM-b.eaveZM ELSE null END AS valueM,CASE WHEN valid THEN abs(c.valueM-(a.eaveZM-b.eaveZM))<1e-9 ELSE false END AS cacheAgreement;
```

### C04 外部屋顶系统与几何坡面的描述

**模块：** 外部屋顶/原拓扑。**分析边界：** 只读取既有外部屋顶与坡面属性，不恢复内部构架。坡面是GeometryRepresentation，不是物理屋顶构件。

**Graph版：** 屋顶系统与几何坡面保持不同身份，只显示已存在的归属边。

```cypher
MATCH (g:V01)
WHERE g:Roof OR g:RoofSurface
OPTIONAL MATCH (g)-[r:PART_OF|MEMBER_OF_ZONE]->(owner:V01)
RETURN g AS anchor,r AS relation,owner,null AS path;
```

**Table版：** 属性检索。

```cypher
MATCH (r:V01)
WHERE r:Roof OR r:RoofSurface
RETURN r.uid AS uid,r.name AS name,labels(r) AS labels,
       r.form AS form,r.slopeDeg AS slopeDeg,
       r.ridgeAzimuthDeg AS ridgeAzimuthDeg,
       r.overhangM AS overhangM,r.areaM2 AS areaM2
ORDER BY uid;
```

### C05 墙轴交接、墙柱包络相交、坡面共边

**模块：** 原拓扑。**分析边界：** 使用有方向的存储端返回atSource/atTarget；这些限定几何关系不证明实体接触、受力或真实构造连接。

**Graph版：** 图中显示原限定几何关系；边的几何字段可点击查看，不升级为受力或构造连接。

```cypher
MATCH (a:V01)-[r:AXIS_JOINS|ENVELOPE_INTERSECTS|SHARES_BOUNDARY]->(b:V01)
RETURN a AS anchor,r AS relation,b AS neighbor,null AS path;
```

**Table版：** 既有关系检索。

```cypher
MATCH (a:V01)-[r:AXIS_JOINS|ENVELOPE_INTERSECTS|SHARES_BOUNDARY]->(b:V01)
RETURN a.uid AS source,b.uid AS target,type(r) AS relation,
       r.atSource AS atSource,r.atTarget AS atTarget,
       r.junctionXY AS junctionXY,r.intersectionKind AS intersectionKind,
       r.boundaryRole AS boundaryRole,r.ruleId AS ruleId
ORDER BY relation,source,target;
```

### C06 前院由哪些墙、柱和过渡空间参与界定

**模块：** D03-T02。**分析边界：** 返回边界参与和已登记区间；围合长度需要按同一切片求区间并集，不能在任意空间直接相加，不能将残余自动称开放。

**Graph版：** 前院的边界参与网络，不是围合长度的并集计算结果。

```cypher
MATCH (s:V01 {uid:'V01:S05'})-[r:BOUNDARY_PARTICIPANT]->(p:V01)
RETURN s AS anchor,r AS relation,p AS participant,null AS path;
```

**Table版：** 分析输入提取。

```cypher
MATCH (c:V01 {uid:'V01:S05'})-[r:BOUNDARY_PARTICIPANT]->(p) RETURN c.uid AS courtyard,p.uid AS participant,p.name AS name,r.uid AS relationshipUid,r.boundaryId AS boundaryId,r.participantRole AS role,r.analysisSliceZM AS sliceZM,r.referenceLengthM AS lengthM,r.solidIntervalBoundsM AS intervals,r.netContributionM AS netContributionM ORDER BY boundaryId,participant;
```

### C07 入口的两侧空间、宿主及相对位置

**模块：** D03-T03。**分析边界：** side-a/side-b是空间角色，opening-host是宿主角色；开口跨度不是已验证净通行宽度。

**Graph版：** 显示两侧空间与宿主角色；点击边查看role，不能把宿主和空间侧混同。

```cypher
MATCH (i:V01)-[r:INTERFACE_OF]->(p:V01)
WHERE i.uid IN ['V01:I04','V01:I05']
RETURN i AS anchor,r AS relation,p AS participant,null AS path;
```

**Table版：** 关系与属性检索。

```cypher
MATCH (i:V01)-[r:INTERFACE_OF]->(p) WHERE i.uid IN ['V01:I04','V01:I05'] RETURN i.uid AS interface,p.uid AS participant,r.role AS role,r.uid AS relationshipUid,i.referenceMode AS referenceMode,i.relativePosition AS relativePosition,i.sideBoundaryMappingsJson AS sideMappings ORDER BY interface,role;
```

### C08 院外参照经前院到前廊的路径

**模块：** D03-T04。**分析边界：** 限定三个外部空间、合成情境、快照、行动者与双向许可；最少跨界数不是步行距离，未验证真实净空。

**Graph版：** 返回原生PATH；保留三个外部空间、情境、快照、行动者及双向许可。Graph为最少跨界路径，不是步行净空验证。

```cypher
MATCH p=(a:V01 {uid:'V01:S06'})-[rs:DIRECT_ACCESS_TO*1..8]-(b:V01 {uid:'V01:S04'})
WHERE all(n IN nodes(p) WHERE n.uid IN ["V01:S04", "V01:S05", "V01:S06"])
AND all(idx IN range(0,size(rs)-1) WHERE rs[idx].contextId='V01-walk-baseline' AND rs[idx].snapshot='V01-synthetic-T0' AND rs[idx].actor='正常成人步行（旧合成情境断言）' AND (startNode(rs[idx])=nodes(p)[idx] OR rs[idx].bidirectional=true))
RETURN a AS anchor,null AS relation,p AS path,size(rs) AS crossings
ORDER BY crossings LIMIT 1;
```

**Table版：** 已知子图路径计算。

```cypher
MATCH p=(a:V01 {uid:'V01:S06'})-[rs:DIRECT_ACCESS_TO*1..8]-(b:V01 {uid:'V01:S04'})
WHERE all(n IN nodes(p) WHERE n.uid IN ["V01:S04", "V01:S05", "V01:S06"])
AND all(idx IN range(0,size(rs)-1) WHERE rs[idx].contextId='V01-walk-baseline' AND rs[idx].snapshot='V01-synthetic-T0' AND rs[idx].actor='正常成人步行（旧合成情境断言）' AND (startNode(rs[idx])=nodes(p)[idx] OR rs[idx].bidirectional=true))
RETURN [n IN nodes(p)|n.uid] AS nodes,[r IN rs|r.viaUid] AS via,size(rs) AS crossings ORDER BY crossings LIMIT 1;
```

### C09 局部面积窗口与空间轮廓

**模块：** D03-T05。**分析边界：** 返回U01声明窗口与S04/S05轮廓。面积并集、子集和层位检查由现有几何程序完成，不冒称全宅比例。

**Graph版：** 仅显示局部分析窗所属对象与空间的实际层级背景；图上的包含路径不代表面积比例已经计算。

```cypher
MATCH (u:V01 {uid:'V01:U01'}),(n:V01)
WHERE n.uid IN ['V01:S04','V01:S05']
OPTIONAL MATCH p=(u)-[:BOT_HAS_BUILDING|BOT_HAS_SPACE*1..2]->(n)
RETURN u AS anchor,null AS relation,n,p AS path;
```

**Table版：** 分析输入提取。

```cypher
MATCH (u:V01 {uid:'V01:U01'}),(n:V01) WHERE n.uid IN ['V01:S04','V01:S05'] RETURN u.areaScopeId AS scopeId,u.areaScopePolygonXY AS scope,n.uid AS uid,n.footprintXY AS polygon,n.groundZM AS groundZM,n.geometryVersion AS geometryVersion ORDER BY uid;
```

### C10 有来源支持的空间用途分布

**模块：** D03-T06。**分析边界：** 只统计声明外部范围内useState=known且来源支持用途字段的对象；同一用途按空间UID去重。

**Graph版：** 用途是空间属性；Graph显示有据用途的空间与来源，不为每个用途字符串虚构节点。频数看Table版。

```cypher
MATCH (n:V01)-[r:HAS_SOURCE]->(src:V01)
WHERE n.uid IN ['V01:S04','V01:S05','V01:S06']
  AND n.useState='known'
  AND all(f IN ['useState','useValues','useScope'] WHERE f IN r.fields)
  AND r.sourceVersion=src.sourceVersion
RETURN n AS anchor,r AS relation,src,null AS path,n.useValues AS useValues;
```

**Table版：** 分组计数。

```cypher
MATCH (n:V01)-[r:HAS_SOURCE]->(src) WHERE n.uid IN ["V01:S04", "V01:S05", "V01:S06"] AND n.useState='known' AND all(f IN ['useState','useValues','useScope'] WHERE f IN r.fields) AND r.sourceVersion=src.sourceVersion UNWIND n.useValues AS use RETURN use,collect(DISTINCT n.uid) AS spaceUids,count(DISTINCT n.uid) AS spaceCount ORDER BY use;
```

### C12 指定局部的开口数量与描述性候选归类

**模块：** D04-T02/D06-T03。**分析边界：** 限W03北侧与W10南侧各一个已声明局部；计数宿主上的Interface而非窗格。CASE只对应现行开口数候选，不是地方立面型或完整配置归类；没有记录时不当作确定无开口。

**Graph版：** 显示指定墙面与每个开口；候选类型是返回的派生标量，不创建类型节点。因展开开口，Graph返回行数与Table版不同。

```cypher

WHERE w.uid IN ['V01:W03','V01:W10']
  AND f.geometryVersion='V01-unified-2.2'
OPTIONAL MATCH (i:V01:Interface)-[:INTERFACE_OF {role:'opening-host'}]->(w)
WITH o,w,f,count(DISTINCT i) AS openingCount
OPTIONAL MATCH (opening:V01:Interface)-[hostRel:INTERFACE_OF {role:'opening-host'}]->(w)
RETURN o AS anchor,f AS relation,w,opening,hostRel,null AS path,openingCount,
       CASE WHEN openingCount=1 THEN 'single-opening-local'
            WHEN openingCount>=2 THEN 'multiple-openings-local'
            ELSE '需核对覆盖，不将未记录当作无' END AS candidate,
       'D06-local-candidate-0.1' AS ruleVersion;
```

**Table版：** 固定合成范围的计数与候选归类。

```cypher
MATCH (o:V01)-[f:FACADE_PARTICIPANT]->(w:V01:Wall)
WHERE w.uid IN ['V01:W03','V01:W10']
  AND f.geometryVersion='V01-unified-2.2'
OPTIONAL MATCH (i:V01:Interface)-[:INTERFACE_OF {role:'opening-host'}]->(w)
```
