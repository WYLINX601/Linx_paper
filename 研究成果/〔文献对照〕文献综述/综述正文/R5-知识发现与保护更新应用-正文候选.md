# R5 知识发现与保护更新应用：从信息关联到有依据的判断

> 问题导向正文候选，未并入全文工作稿。区分检索、分析、决策支持与保护效果，不据局部案例宣称领域全貌。证据表见[R5正文依据与待核项](R5-正文依据与待核项.md)。

<!-- body:start -->
## 1. 信息关联是知识应用的基础，但不等于知识发现

建筑知识组织的价值应落实到具体任务：研究者能否找到与某一对象相关的资料，能否比较不同对象的特征与关系，能否形成有证据的解释，以及这些认识能否为保护更新提供可审查的依据。上述任务存在联系，却不能用“建成图谱”一并替代。检索既有信息、依据明确规则推导隐含关系、发现样本中的关联，以及判断某种保护措施是否适当，需要不同的输入和验证。

Rasmussen等（2021）的建筑拓扑本体（Building Topology Ontology，BOT）研究显示，形式化关系与公理能够支持区域、构件及其跨层联系的查询；三个建筑模型上的实验还报告了不同查询的执行表现。这类结果证明的是特定表达和查询机制的可执行性，而非新建筑规律的发现。郭锐等（2026）则以历史建筑案例，将构件、修缮资料与保护要求相联，展示查询保护信息的组织路径。两者分别提供语义执行与应用场景的证据，不能合并解释为已证明保护决策效果。[^bot][^guo]

因此，讨论知识发现时，首先需要说明“新增的认识”是什么。若输出只是原资料的重新呈现，应评价其检索与追溯能力；若声称发现了类型组合或空间关联，则应说明比较对象、分析单位、关系来源及反例。这样的区分不是否定资料组织的价值，而是使不同价值获得各自适当的证据。

## 2. 从可查询关系到建筑学认识，还需要分析与解释

吴莹（2018）的研究把空间类型分析、语义表达、图模型运算和场所解释串联起来：先形成住宅、街巷及桥头等对象的关系描述，再比较不同建模方式的量值，最后回到周庄的具体空间讨论。这说明关系模型可以成为连接局部空间认识与整体比较的中介，建筑学解释并不必然被计算替代。[^wu]

但模型所得量值与真实空间属性之间仍需论证。该研究在加入空间特征、改变节点或点链转换后比较指标，计算结果因而同时受空间记录和编码规则影响。借鉴这种路径时，需要区分对象实际差异与表示粒度差异，不能把图指标直接当作人的行为、空间活力或文化意义已经得到验证的证据。尤其对于传统民居比较，同一建筑的多个构件、同一村的多个住宅及跨村样本具有不同分析层级，不能因它们都成为节点就混用分母。[^wu]

Messaoudi等（2018）从另一方向连接定性与定量：将材料、劣化、构件等不同主题标注置于共同空间参照，通过区域重叠与形态描述量探索关联。其贡献在于明确了关联数据如何生成，并允许专家补充或反对某项观察。但是，空间共存只是进一步解释的条件，不独立证明材料与劣化之间的因果；而且论文中的关联引擎仍包含待实现内容。该文更适合作为关联分析的组织路径，而非既成普遍规律的证明。[^mes]

综合而言，知识图谱适合保存和筛选关系，建筑规律仍需在可比资料、合适分析方法和具体建筑解释之间建立证据链。把检索结果返回原图像、测绘资料与文献，不仅是展示功能，也是判断某种关联究竟来自现实对象、资料缺失还是编码规则的重要条件。

## 3. 决策支持应提供可追溯候选，而非替代专业判断

保护更新应用比关系查询更进一步，因为输出可能影响实际对象。王垚（2025）的木构架研究提供了较明确的任务链：从构件类型、损伤部位、残损类型和程度组织查询，在知识图谱中找到修缮方法及其关联项目，再将结果返回信息模型界面。案例中，方案依据关联项目数量排序，形成供管理方参考的候选方法；健康评估则使用另一套指标与权重计算。[^wang]

这一案例说明，知识组织可以把分散经验转为有来源的检索结果，并使评估、记录和方案查找在同一工作环境中衔接。但出现于较多项目的方法，不因此就是当前构件的最佳方案。项目来源的材料、损伤原因、受力条件和实施效果，仍会影响可迁移性；原文所展示的查询过程也不能替代具体工程的专业判断。因此，其较可靠的借鉴点是“按问题组织检索并保留相关项目”，而非把频次排序直接升级为效果最优的推荐。[^wang]

郭锐等（2026）把规范与保护流程连接的案例，同样提示知识应用需要保留依据及适用对象。不过，规范信息能够被检索，不等于条款适用性已经核定，更不等于自动完成合规判断。该文报告的效率提升缺少足够清晰的对照与成本口径，因而适宜说明一种应用路径，不宜据此量化本研究预期收益。[^guo]

对于传统民居风貌研究，以上应用不必整体照搬为修缮决策系统。更贴近当前范围的任务是找出具有特定特征组合的实例、比较不同组团的空间组织、追溯某一类型判断的资料依据，并为后续保护讨论提供可复核的对象与关系。由文献引出的这些用途只是待检验的应用方向，不代表本研究已经具备工程诊断或设计推荐能力。

## 4. 应用价值需要任务对照和成本证据

比较上述研究，可以区分四种证据：模型能否表达所需信息，查询能否正确得到预期结果，结果能否支持领域判断，以及使用后是否改善实际工作。BOT的导出与查询实验主要支撑前两类；Messaoudi等的工作主要提出有部分实现基础的证据关联框架；王垚的案例展示了面向具体任务的系统使用；郭锐等则提供保护信息整合示例。它们的验证对象不同，不能仅凭都使用知识组织技术，就累积为同一种“有效性”结论。[^bot][^mes][^wang][^guo]

据此，本文对应用评价的综合判断是：应从明确任务出发设置参照，而不是从平台功能反推收益。检索任务可检查答案是否正确、是否遗漏关键对象及能否返回来源；比较任务需检查分析单位、缺失处理与编码一致性；辅助判断任务则需考察结果是否提供了适用且充分的依据。若进一步声称节约时间或提高效率，还需计入资料整理、标注、审核和维护投入，不能只计算一次查询所耗时间。这些是由文献证据差异提出的评价要求，不是本轮已经完成的实验。

因此，知识发现与保护更新应用应采取逐层兑现的论证方式：先保证事实与关系可追溯，再证明查询及比较任务可用，最后讨论其对建筑认识和保护工作的增益。对于景宁传统民居，图谱的意义不在于把已有资料改画成网络，而在于能否帮助研究者形成、核查和复用跨样本、跨维度的建筑认识。该价值必须由真实任务表现支撑，不能由节点规模、可视化复杂程度或技术名称预先保证。
