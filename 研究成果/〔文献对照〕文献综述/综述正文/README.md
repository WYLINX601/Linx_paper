## 综述之间的分工

R1讨论分析方法，R2讨论地方研究积累；二者分别回应“怎么认识”与“已经认识到什么”。R3讨论资料及信息管理，R4讨论语义表达，R5讨论分析和应用证据。共用论文时只引用服务于该篇问题的部分，不能把同一案例跨篇出现当作多项独立验证。

这是本组综述的**写作分工**，不是新确认的上层研究问题关系，也不是对现行大纲的重排。R4与R5沿用既定1.3综述任务映射中的两个工作专题；正式章节采用待后续审阅。

## 综合评述候选

就本组所核材料而言，传统民居研究为对象拆解、类型比较及地域解释提供了基础，数字化与语义建模研究则为资料关联、关系查询和应用衔接提供了可借鉴的路径。仍需在本研究中落实的，不是再次证明这些技术“可以使用”，而是明确景宁民居的可比对象与特征，保存分类及关系判断的来源，并以真实资料检验跨样本、跨维度分析与有限保护复用是否成立。这里提出的是本研究的论证任务，**不是对整个领域空白的宣告，也不是研究有效性已成立的结论**。

这段是综合判断候选；各组成论据回到R1—R5正文和依据页，不作为无引文的独立事实引用。

## 完成范围与阅读限制

- 形式：沿用用户选择的Rapid review；中英文，不设起始年份，以既有核读材料和定向补读为基础，未声称全数据库覆盖。
- 本轮R2/R3由文学综述角色子任务提供候选，主会话检查后发布；R4/R5由主会话核读并撰写。不是双人全量筛选或独立全稿审稿。
- 新增三份来源的单篇卡片先建后读，保留局部精读状态、Zotero身份、版本及PDF页序；详见[新增来源核读记录](新增来源核读记录.md)。
- 题录年份冲突、同源报告、不同样本单位及未核的应用效益在支撑页保留；不把文献记录数量写成现存建筑数量。
- 本轮不改全文工作稿、正式大纲、研究问题映射、BOT双基准、案例JSON或Neo4j，不恢复内部构架、时序或感知分支。
- 新文件按已授权的ExFAT兼容路径写入并回读；它提供可恢复的排他创建，不提供完整文件原子可见性。
