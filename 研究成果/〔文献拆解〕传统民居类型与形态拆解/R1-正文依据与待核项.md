[阅读正文候选](R1-传统民居建筑形态与类型研究-正文候选.md) · [既有精读证据主源](证据与阅读记录.md) · [[主题研究/〔研究方法〕类型识别与比较/〔研究方法〕类型识别与比较.md|相关主题]]

## 1. 本次回答的问题与中心判断

沿用快速综述的工作问题：**已有研究如何选择民居形态的分析对象与尺度，依据哪些特征或关系进行分类，怎样从分类走向类型、原型及空间解释，其认识在什么资料与样本条件下成立？**

中心判断为阅读者综合：类型研究的价值不只是提供地方类型名录，而是在明确的对象层级上，用形态判据和空间关系解释共性、差异及组合。具体景宁分类与方法采用仍待确认。这不是对全部类型学理论的通用定义，也不自动建立R1与现行上层研究问题、章节或论点的正式映射。

### 正文组织与删减

- 第一部分回答“分类对象是什么、依据什么”：保留整体—局部层级，以及要素特征与组织关系的区别。
- 第二部分回答“类型怎样形成、能够认识什么”：对照形制归纳、组合分析、聚类和既定类型内的量化比较，不按作者逐篇排列。
- 第三部分回答“什么证据支持解释”：把原型参照、原型推辨、历史起源和较大尺度的空间组织分开。
- 第四部分回答“本研究可借鉴什么”：提出有据的分析取向，不预先形成景宁类型体系或领域空白结论。

正文不再携带完整报告级比较表、检索操作日志、全部方法疑点和下一步任务清单。上述材料保留为支撑，不等于丢弃未被正文点名的报告。本次从原快速综述的13份报告中选择8份直接支撑正文；不将报告数视为独立研究数，更不合并建筑、院落、侧样或区域数量。

## 4. 术语口径

下表是本候选稿的写作口径，不作为类型学领域的权威定义。

| 用语 | 本稿含义与边界 |
|---|---|
| 形态特征 | 用于描述和比较的具体表现，包含轮廓、尺寸、比例、材料等；不与类型标签混同 |
| 分析对象／分析单元 | 当前被描述、分类或比较的对象；整宅、合院细胞、功能空间、侧样、形态区域分别记录 |
| 类型 | 基于明确对象与判据归纳的类别或构成模式；不预设必须互斥，也不与任意聚类标签自动等同 |
| 原型 | 保留具体作者的分析参照或综合推辨含义，不统一改写为年代最早的实物 |
| 空间关系 | 组成、围合、轴线、组合或联系等有具体依据的关系；不把所有关系都当作可通行关系 |
| 建筑组团 | 当前研究关注的分析对象之一，具体边界待资料与研究问题确定；不直接等同于合院细胞或规划管理单元 |
