案例JSON是维护主源。数据库通过已配置SSH-backed MCP访问；本包为实际返回的离线材料。固定查询不是触发器或通用规则引擎，EXPLAIN没有计划正文，不能称性能验收。

- [审核查询](审核查询.cypher)共有Q01—Q08；最前面的可选Q00只作图显示，不计入查询验收。
- Q05／Q06必须加载[查询参数](查询参数.json)中的caseId、modelSha、expectedRule，不能仅传caseId。expectedRule由JSON编译；匹配版本之外还核对规则内容。
- [查询返回](查询返回.json)、[数据库读回](数据库读回.json)、[核验记录](核验记录.json)是实际执行结果；记录原生valueType，不能仅按JSON显示判断整数与浮点。
- 分类参数测试是只读合成输入，坏载荷测试被拒绝且全图指纹不变；两项读回反例测试改变查询期望参数，没有改动已保存节点。
- MCP启动时探测GDS版本报缺失，本任务不使用GDS；普通Cypher已实际执行通过。没有因此安装、重配数据库或引入直连驱动。
- 初次写入是限定命名空间的一次事务创建，不是upsert。已存在执行标记时拒绝重复write，必须verify或人工协调。
- [恢复说明](恢复说明.md)与[写前逻辑快照](写前逻辑快照.json)保留恢复依据；逻辑快照不是二进制备份，没有宣称演练恢复。
