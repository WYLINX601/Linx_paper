## 1. 这次要回答什么

**屋顶的外形、构架的组成及其与院落空间和墙体的关系，怎样共同构成可描述、可比较的民居特征？**分析同形异构、同构异形的可能组合，但不预写这些规律必然存在。

组织顺序改为：**共同问题 → 通用对象与特征／关系 → 景宁文献中的具体表现 → 必需输入与判断口径 → BOT对应及最小表达。**分析项是任务，不是六种实体类别；共同定义也不表示每栋建筑都具有同样的构件或空间。

D01关注整体尺度、比例和组合；D02关注屋顶形态与构成、空间对应。D02接续D01-T03的檐脊、出檐和轮廓需求；**T03尚未实例化**，只有未来同对象数据可对应时才复用。D01-T04及T06未覆盖内容不因本轮而完成。院落的一般空间组织留给后续D03，本表只处理它与屋顶、构架的交叉问题。

**文献作用：**S1、S2提供景宁材料中的院墙、后厨天井、嵌排、柱筒与屋面分层观察和分析方法，并非通用对象分类标准。两篇相关调查不视为独立互证；本表的共同操作口径与术语映射是研究者提出的候选设计。[S1 §2、图3—7；S2 §3.4、§4.2]

## 2. 对象、特征、术语与资料分开组织

### 2.1 通用对象与工作边界

以下是**D02的候选操作定义**，不是建筑术语标准或已经验证的完整本体。以BOT的区域、空间与组成对象区分为参照，在其上细化；不把所有对象都纳入一个严格的组成树。[S3 B-C01—06、B-A04；S4 U02—03]

| 对象／层面 | 本研究暂定含义与识别边界 | 关键区分与表达条件 |
|---|---|---|
| 建筑与屋顶系统 | 建筑复用既有身份；屋顶是具有实际覆盖及构造意义的组成系统，说明所服务的建筑或局部 | 屋顶不是整栋建筑，也不是单片无厚度坡面；按关联需要评估独立对象 |
| 构架／榀架 | 构架为有组成依据的实际构件组合；在能辨认分榀组织时，以定位明确的一榀作为比较单元，说明方向、涉及构件和边界 | “榀”不是所有建筑必须具有的单元；只有整体系资料时保留粗粒度，不补造各榀 |
| 梁、柱、檩、墙等构件 | 按位置、形态及有据的构造作用识别实际组成对象，分别记录类别与身份 | 梁与枋等不因方向相近而强并；竖直外观不独自证明柱的承载作用；没有逐件资料不按数量生成构件 |
| 院落空间 | 本表暂指由建筑、墙体等限定并可识别地面范围、具有露天部分的院落空间；保留实际围合、开敞范围和时点 | 不等于含房屋的整个宅院；也不等于屋顶开口投影。局部加盖时记录覆盖状态，不能只由原名推断当前露天 |
| 房间、廊等空间 | 按实际或有依据的理论边界及使用情况识别，范围与功能分别说明 | 不把厅堂、后厨等功能名称直接当作几何边界；本表仅记录与屋顶／构架对应所需部分 |
| 构架划分的“间” | 当资料支持时，暂以相邻榀架／柱列界定的一个组织单元讨论，另行声明排列方向、进深范围和边界依据 | 是本研究限定用法，不是“间”的唯一通用定义；不自动等于房间，也不预先强定BOT类别或节点 |
| 几何表示 | 屋面分析片、檐脊线、断面轮廓及构件控制点等具有位置和划分依据的几何内容 | 与实体区分；普通几何引用归对象，需独立关联时再评估分析对象节点 |
| 构型与资料表达 | 构架形式是对象的配置特征；侧样图、平剖面图、定盘图等是记录或表达它的资料 | 同一形式可有多个实例和多份图；图示不因同形而被认定为同一实体 |

**“间”分开记录：**构架组织单元、使用意义的房间、间宽／进深、间数。计数须声明方向和边界；量宽须声明轴线间距还是净距，不混算。“间”是否适合独立对象、如何关联三维范围，仍需实际例子核验；本轮不展开完整平面分类，也不把所有构架间隙命名为“间”。

### 2.2 原词到通用表达的映射

映射保留**来源原词—具体所指—共同表达—映射性质—判定依据**；同义、上下位、部分重叠和仅有关联分开。原词不被规范名覆盖，同一实例不会因有两种称谓而建两次。

| 来源词／旧表述 | 共同表达或归属 | 映射性质与使用条件 |
|---|---|---|
| 嵌排 | 有位置和组成依据的榀架／排扇 | 来源语境内称谓对应：S2 PDF60／印刷49注17解释当地称谓；仅在对应资料语境内采用，不能凭词把不同建筑的实例去重 |
| 侧样 | 构架的侧向形式／配置特征 | 形式概念对应：S1 §2—3据此讨论分型；不是只能指一张图，也不与一榀实物直接同一 |
| 侧样图、剖面图 | 资料／表示 | 表示层归属：保存图纸性质、图号、切取或观察方向及代表对象；不同图种不宣布完全等价 |
| 后厨天井、方形／“一”字型天井 | 院落空间及其位置、开敞形态、原作者类型 | 有条件的上位归并：对符合2.1工作定义的对象暂作归并；不是“所有天井＝所有院落”的同义规则。保留原形制名，只有边界足够时再赋共同形态描述 |
| 柱筒、直筒 | 构件配置；具体竖向构件的落点及构造作用 | 部分对应／需消歧：原文柱与筒的计数口径另存；S1注3解释直筒为不落地柱，但不能据此把所有短柱、所有不落地构件都改名直筒 |
| 后架、拖尾 | 构架的有定位局部及变化 | 有定位的局部对应：保留原词，按参照柱／线界定；不把地方方向约定当地理方向 |
| 屋水、算水 | 屋面几何与地方营造规则 | 是有关联而非完全同义；分段坡度是几何描述，传统算法另存适用段、单位、规则及来源 |
| 几柱几筒 | 原作者的构架配置类型或汇总描述 | 类型描述而非实体同义：可用于同口径比较，不是通用实体类别；原词不能替代逐件身份与空间配置 |

**院落—天井处理示意（不是新增真实实例）：**同一空间保留一个身份；共同对象类型暂为院落空间，来源称谓保留后厨天井，位置／边界／形态与屋顶、墙体关系分别记录。后续若原词只指屋顶开口、整个宅院或范围无法定位，则不强行套用此映射。

### 2.3 共同前提与不适用情形

- 对应前提是同栋、同一状态／时点、对应部位及相同测量基准；跨栋比较另须同一对象层级和分类口径。营造方位与实测地理方向分别记录。[S1 PDF3／印刷12图5；S2 PDF60／印刷49图3.9]
- 资料区分现场测绘、匠师手稿、作者分析示意、复原图及合成图。形式相似不证明图纸属于同栋；多图证据也不能自动认定相互独立。
- 本轮共同口径主要面向能识别屋顶、空间及构成关系的传统民居；分榀、杆件配置、檩位等按结构与资料条件启用。承重墙体系不为套表强造榀架，缺少构架资料也不意味着构架不存在。
- “有／明确无／未知”描述对象状态；“未记录／遮挡等不可识别”说明未知原因；“不适用”表示本问题或粒度对该对象不成立。原文未提及不能编码为无。
- 候选研究需求保留而非删除；按当前范围决定，内部构架相关任务暂缓纳入，不作为本阶段必采或必填。逐件构件、逐榫做法和地方算法也不因资料日后出现而自动启用，仍须另行确认分析用途与纳入范围。

## D02-T01 屋顶形态与分段组织

**预期结论：**描述屋顶轮廓、坡向及局部屋面之间的高低、连续或中断关系，分层作为其中一种可能表现；先形成可定位描述，不仅贴一个屋顶类型名。

**对象与范围：**一栋建筑的屋顶整体及所选局部／断面。附属屋面是否另属其他建筑须按实际身份判断，不能只因轮廓分开就分栋。

| 必需数据 | 记录口径 | 用途／单位 |
|---|---|---|
| 屋顶及局部身份 | 明确覆盖对象、时点、局部划分依据；实体层与几何分片分开 | 防止对象重复；身份／说明 |
| 檐脊线及断面 | 接续D01-T03需求；已有且经核对的数据共享复用，保留线段起止、方向、对应建筑部位和高程基准 | 轮廓与起伏；m |
| 分段位置；分层时的上下屋面 | 定位转折／中断；仅有分层时分别定位上层收尾、下层起点，不强制所有屋顶存在上下两层 | 分段／分层描述；m／局部引用 |
| 出檐与搭接／间隙 | 指定同一断面、水平或垂直方向及量取端点；没有内部证据不把遮挡当搭接 | 几何对照触发；m |

**判断与计算：**优先保留原始轮廓；存在对应且可比的上下屋面位置时计算局部高差或水平偏移。正负号须随参照说明。分层与连续折线不同，影像阴影或网格缝不直接判为屋面分层。

**候选表达：**普通高度、方向、分层描述直接归相应对象；具体局部作为几何引用。实体屋顶可参照BOT B-C06，几何关联参照B-R13／B-D01；纯坡面不机械贴Element。来源关系限定所支持的几何字段和局部。[S3；S4 U02-B、U10]

**依据与限度：**S1 PDF4／印刷13的§2.3.2、图7及S2 PDF62—63／印刷51—52描述屋面分层及后廊变化，S2具体分层做法见PDF63／印刷52。本表的定位、单位和差值口径为本研究候选；作者记载的特定尺寸不设为所有建筑的识别阈值。

**审核记录：**方向已获认可，具体口径待审核。重点：首轮是否采用“屋顶整体＋有定位的分析片／断面”，而不把每个网格面建节点？

## D02-T02 构架组成与构件配置

**当前采用状态：暂缓纳入，保留候选储备。**以下定义与数据需求不作为本阶段必采或必填项。

**预期结论：**说明构架由哪些构件组成、它们的位置与配置如何变化；有分榀依据时比较不同榀，而不是用一个柱筒数概括全栋。

**对象与范围：**指定建筑的构架及可定位的局部或榀架；根据分析问题选择整体、分榀或必要构件层级。房间、构架划分的间和图示分别处理。

| 必需数据 | 记录口径 | 用途／单位 |
|---|---|---|
| 构架身份、位置与命名 | 局部／榀位、方向、组成边界；地方原名及营造方位另存 | 同对象对应和跨位置比较 |
| 构件配置与落点 | 识别必要梁、柱、檩等的位置及落点；原文柱／直筒类别、是否落地及依据单列 | 组成与配置；对象引用／位置 |
| 计数范围和结果 | 明确整架／单榀／局部、所计类别及未知项；原文几柱几筒整组名称另存 | 同口径数量比较；个 |
| 局部分界与相对位置 | 用参照构件／线界定前后或局部范围，后廊、后架作为有依据的应用 | 定位变化、复用T04 |
| 图纸对应信息 | 图号、页码、尺度依据、榀位、图纸性质和时点 | 判断侧样图代表什么对象 |
| 构件组成及连接对象 | 说明属于哪一构架、连接谁及局部位置；组成、连接、支承分别记录 | 支持配置比较，支承依据转T03 |
| 间的边界与尺度（条件项） | 仅在需研究构架排列／空间划分时启用；记两侧榀架或柱列、进深范围、排列方向；间宽声明轴线距或净距 | 间数／间宽与房间分开；个／m |

**判断与计算：**比较前统一构件类别、范围、可见条件与方向。逐件识别完备时计数可由组成对象派生；只有文献汇总时保存汇总属性，不按数量补造实体。间宽比较须采用相同量取基准；计数未知部分不能当零，单榀不能代替其余榀。

**景宁文献映射：**分榀侧样作为观察形式和比较方法；嵌排作为特定来源中实际构架的称谓；柱筒及几柱几筒保留其分类和计数口径。侧样形式、侧样图与实际榀架三者不混同。

## D02-T05 屋面几何与构架高度的对应

**当前采用状态：内部构架高度及其与屋面的对应分析暂缓。**可核验的屋面外部几何可以独立讨论，不据外皮标高推算未知檩位、柱端或内部构架。

**预期结论：**在指定断面内描述屋面起伏与构架控制位置的几何对应；具备明确条件时比较文献做法与实测，而不是自动套用一套“畲族屋顶算法”。

**对象与范围：**同一定位断面中的屋面轮廓与构架控制部位；有分榀依据时按榀比较。檩心、檩顶、柱端与屋面外皮不是同一标高点；具体构件及地方名称另存，不把每种屋盖都预设有相同的柱筒配置。

| 必需数据         | 记录口径                                      | 用途／单位        |
| ------------ | ----------------------------------------- | ------------ |
| 断面与控制点       | 断面位置、方向、各点代表的几何部位和先后顺序                    | 确保高差与水平距对应   |
| 水平距离与高程      | 同一坐标／高程基准；水平投影距而非斜长；单位明确                  | 分段坡度；m       |
| 构件控制部位的高度与位置 | 明确构件／部位、起算面及终点；有柱、直筒、檩时按来源细化；保留构造层间偏移是否已知 | 建立几何对应而非同值假定 |
| 地方算水规则       | 原文公式、术语、匠师／资料身份、适用段、原单位和版本                | 仅在明确任务下对照    |

**本研究候选计算：**在同一断面内，以正的水平投影距Δx和对应高差Δz计算分段斜率k＝Δz／Δx；需要倾角时另按明确约定换算。多段折线保留各段，不用未经说明的平均值代替实际轮廓。整体端点坡度与各段斜率的算术平均不是同一口径，禁止混用。

Δz按已声明的断面行进方向取后点减前点；传统尺寸换算须有该资料适用的尺度依据，依据不明时保留原单位，不作绝对高度对照。

**景宁文献映射：**屋水、算水与柱筒／檩位是本项地方术语及具体做法，不与一个坡度数值完全同义。传统营造规则与本研究几何计算分别保存。

**适用与不适用：**只有屋面几何时可描述轮廓，但构架对应保持未知；没有相应檩或柱筒系统时不强套该类字段；地方算法无明确出处或单位时暂缓计算，不因此删除几何需求。

**候选表达：**控制点／几何序列和版本归对象或已有几何表示，普通值不节点化。若需要保存可独立审核的计算结果，才建立带输入引用和规则的结果记录。几何关联与求值由本研究补充，BOT不提供屋水计算规则。[S3 B-A08；S4 U10、U11]

**审核记录：**方向已获认可，具体口径待审核。重点：是否先采用可复查的几何记录和分段坡度，把有单位／符号疑点的地方公式暂缓实现？

## 4. 通用性检查与最小表达

### 4.1 用不同情形检查是否强套地方模式

以下为**研究者构造的语义审核情形**，不是新增真实样本，也不是已运行的图谱测试：

| 审核情形 | 本稿应允许的处理 | 会使定义需要修订的情况 |
|---|---|---|
| 同一空间有院落、天井两个称谓 | 核边界后共用一个身份，原词与出处并存 | 两词在来源中实际指不同范围，不能强并 |
| 某民居有院落但原文不用天井一词 | 依空间特征记录，不以名称作为纳入条件 | 现有工作定义漏掉与研究问题相关的空间形态 |
| 资料明确无后厨天井，但其他位置有前院 | 分别记录部位，不把局部无推广为全宅无 | 当前边界或对象层级无法区分两处空间 |
| 有屋顶外观但内部构架不可见 | T01有据描述，T02／T03相关项未知 | 系统被迫从外形补造构架或支承 |
| 无可识别分榀体系 | 不强造榀架和柱筒，保留适用的屋顶／墙体问题 | 体系只有分榀入口，无法表达其他组织方式 |
| 构架划分的间与房间边界不同 | 两类单元分开，尺寸与数量归各自口径 | 为凑一一对应而删改实际边界 |

**当前结论仅为设计检查：**候选表能说明上述处理方式；跨案例复用、真实数据可获取性、字段有效性及三维关联仍待应用验证，不宣称已建立普适体系。

### 4.2 从数据到图谱


以下是**候选模式说明，不是已建实例或执行结果**：

1. 建筑保留同一身份，关联其屋顶、构架及必要空间；不同分析项引用同一对象。对象类别、特征维度、地方类型、分析任务与资料表示分别记录；一行表或一个导图节点不自动成为实例。
2. 屋顶及构架保存自身的稳定属性；不为“屋顶输入”“柱数输入”“坡度输入”默认建立记录节点。
3. 资料来源按同份同版本共享；对象—来源联系限定具体字段、PDF页码／图号／局部及判断身份。资料存在不代表全部属性都被支持。
4. 构件组成、几何对应、连接和支承分开；简单联系用边及局部说明，必要的多方联系才评估界面节点。
5. 跨图对应须能回答“哪栋—哪一局部／有分榀依据时哪榀—哪个部位—哪个时点”。只有一张外观照片时允许形态记录，内部构架保持未知，不补造。
