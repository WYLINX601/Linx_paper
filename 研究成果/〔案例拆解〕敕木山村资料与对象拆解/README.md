## 用途与限制

主要服务于传统民居的院落/外部空间、立面表层、组合及地形关系资料准备；文献已有类型与特征按出处保存，本研究后续类型分析另行开展。内部构架、时序演变和人的感知不因文献出现相关内容而恢复。文化、区域文献保留其自身贡献，非本村事实不下沉到本村实例。

没有导入Neo4j，没有合并蓝村长家、28号、族长四合院与展馆，没有生成逐栋坐标或三维区域。论文时点、调查日期与2026现状分开。

[生成脚本](../../项目管理/敕木山资料拆解/generate_views.py) 从本包主源和既有资料索引生成派生文本；[原生图脚本](../../项目管理/敕木山资料拆解/素材审核图脚本.md) 通过已安装Excalidraw原生API序列化图源。更新既有正式文件仍需最新SHA、mac-paper备份与验证，不由脚本自动覆盖。

## 院落与外部空间：文献成果提取示例

当前版本0.3。以作者已经形成的形制、特征和空间组织认识为中心，提取、整理和积累成果，而非重新审视其成立与否。

- **先看 [成果与关系视图](院落与外部空间审核.html)**：形制与组合、前后院组织、引水与生活三个主题。点击类型、要素或关系，可读特征、作者原文、配图和Zotero原页；“作者的成果表述”按来源保留综合认识。
- [同源文字说明](院落试例说明.md)：成果陈述、类型与特征、文献所述联系、图片说明及准确出处。
- [执行记录](院落试例核验.json)：来源与阅读范围、独立定向提取、生成及交互检查；不将提取质量检查表述成作者成果被重新验证。
- [调整前快照](../../archive/2026-11-03-院落示例成果提取重组前/README.md)：保存旧0.2主源与可读页面、原生成器及旧核验记录。

“四合院”等类型可先以名称和出处独立保存，案例作为补充。照片局部观察集中在“图片说明汇总”，不再作为主图节点；不同文章的描述各保留作者归属。

唯一维护源仍是[拆解主源](拆解主源.json)的 `courtyard_pilot`；`papers/objects/relations`及原32项资料索引保持不变。首轮主表与Excalidraw仍表达原首轮材料；本例页面和说明由[专用生成器](../../项目管理/敕木山资料拆解/generate_courtyard.py)生成，见[生成说明](../../项目管理/敕木山资料拆解/院落试例生成说明.md)。HTML为自带数据和图像的离线页面。此次不调整正式D03、双基准、V01、Zotero或Neo4j。
