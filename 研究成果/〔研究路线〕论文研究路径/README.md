### 图示分工与约束

1. 左侧按现行六章定位；中间组织每章的主要研究任务；右侧概括“研究基础—体系与方法—实例应用与认识—综合归纳”。这些是图示归组，不改章目。
2. 第三章区分分尺度特征表达、统一图谱模型与类型比较方法；第四章区分输入资料质量与建成图谱质量；第五章以分尺度分析、跨尺度综合及建筑学认识为中心，再评价方法作用。
3. 第二章的理论方法仍需比较和取舍，不因入图认定已经全部采用。三维关联分别承担方法、可核验范围内的实施及分析用途，不是全部非空间事实或分析的强制前提。
4. 合成试建、内部构架、历时演变及人的感知不借本图恢复为论文主线。过程支线和反馈仍在[[研究成果/〔研究路线〕论文研究路径/研究路径工作图.md|研究路径工作图]]维护；本图不是完整的执行时序或全部依赖网络。
5. 标题和顺序仍以大纲YAML为准，依赖与反馈以路径JSON为准；需修改时先核对主源，再显式更新图源与同名导出。本图尚未接入`paper-maintain sync`自动重绘。
