## 可逐项回溯的设计记录

### O01 空间划分可以依据建筑意义

- **原状：**Space定义偏概括，未显式记录连续空间的分界依据。
- **本轮改动：**补充语义分界与新空间的划分体系、依据、状态；堂屋和前廊可以保持两个节点。
- **转换理由（研究者判断）：**把用户已确认的空间理解转成可检查规则。
- **实现位置：**Space定义、spaceIdentityContract、space_division_basis；演示S_HALL/S_VERANDA
- **验证边界：**真实民居如何划分仍需平面、现场及建筑学判断。

- **[ISM01](zotero://open-pdf/library/items/5X32QFZG?page=7)** Development of an Indoor Space Semantic Model and Its Implementation as an IndoorGML Extension，2019；PDF 7／印刷 7，§2.2.1–2.2.2、图3。原文支持：区分形态与连接描述及语义描述：前者包括围合、形状、尺寸、开口，后者包括用途、楼层、建筑标签；可按应用扩展。 限度：不能将空间名称、用途和围合程度压成互斥单一分类。
- **[ISM02](zotero://open-pdf/library/items/5X32QFZG?page=9)** Development of an Indoor Space Semantic Model and Its Implementation as an IndoorGML Extension，2019；PDF 9/10／印刷 9/10，§3.1.2。原文支持：半开放/半围合空间可含天井、阳台、前廊等，不要求所有方向完全围合。 限度：原文的容量、阻抗等服务于疏散场景，本轮不照搬为风貌核心字段。
- **[ISM03](zotero://open-pdf/library/items/5X32QFZG?page=10)** Development of an Indoor Space Semantic Model and Its Implementation as an IndoorGML Extension，2019；PDF 10／印刷 10，§3.2.1。原文支持：Pseudo opening没有实体框架，可以是墙上缺口，也可以产生于空间细分；开口记录连接空间、状态及可达限制。 限度：无门框不自动证明任何人或任何时点可通行；堂屋—前廊是本研究的迁移示例。
- **[BOT01](zotero://open-pdf/library/items/6XP3U4GG?page=8)** BOT: The building topology ontology of the W3C linked building data group，2021；PDF 8／印刷 149，§3.2、图2。原文支持：BOT区分Zone、Element、Interface；三类彼此不相交。Zone含Site、Building、Storey、Space。 限度：论文描述BOT v0.3.1；我们的Dwelling可能是多体研究单元，不可直接等同bot:Building。

### O02 增加可描述的空间界面

- **原状：**只有空间—空间边，难以记录某一个连接位置的性质。
- **本轮改动：**新增Interface和interface_of、realized_by；开口与墙门实体分开。
- **转换理由（研究者判断）：**界面承载分隔、开口与连接情况，允许无实体门框的分界。
- **实现位置：**Interface及两种演示界面
- **验证边界：**PseudoOpening与Interface为本研究部分对应，未宣告外部标准等价。

- **[BOT01](zotero://open-pdf/library/items/6XP3U4GG?page=8)** BOT: The building topology ontology of the W3C linked building data group，2021；PDF 8／印刷 149，§3.2、图2。原文支持：BOT区分Zone、Element、Interface；三类彼此不相交。Zone含Site、Building、Storey、Space。 限度：论文描述BOT v0.3.1；我们的Dwelling可能是多体研究单元，不可直接等同bot:Building。
- **[BOT03](zotero://open-pdf/library/items/6XP3U4GG?page=10)** BOT: The building topology ontology of the W3C linked building data group，2021；PDF 10／印刷 151，§3.5。原文支持：Interface用于细述空间、构件及二者之间的关系，可附加空间之间通行类型与限制；interfaceOf关联相应对象。 限度：Interface不限于通行开口，也不等于墙或门实体。
- **[ISM03](zotero://open-pdf/library/items/5X32QFZG?page=10)** Development of an Indoor Space Semantic Model and Its Implementation as an IndoorGML Extension，2019；PDF 10／印刷 10，§3.2.1。原文支持：Pseudo opening没有实体框架，可以是墙上缺口，也可以产生于空间细分；开口记录连接空间、状态及可达限制。 限度：无门框不自动证明任何人或任何时点可通行；堂屋—前廊是本研究的迁移示例。
- **[ISM04](zotero://open-pdf/library/items/5X32QFZG?page=14)** Development of an Indoor Space Semantic Model and Its Implementation as an IndoorGML Extension，2019；PDF 14/15／印刷 14/15，图9—10、§5。原文支持：SemanticSpace对应空间单元，SemanticOpening对应边界并支持连接关系；论文仍需完整案例验证及后续官方采纳讨论。 限度：这是IndoorGML扩展提案，不是已正式采纳标准；PseudoOpening与本地Interface的映射由研究者提出。

### O03 邻接、通行、相交与分隔分别表达

- **原状：**adjacent_to包含“共享或紧邻”两种含义；通行边缺少界面与情境。
- **本轮改动：**邻接收紧为共享边界；通行必带via及情境；新增相交、界面分隔与开口状态。
- **转换理由（研究者判断）：**防止靠近即邻接、邻接即通行、无隔断即随时可通过。
- **实现位置：**4项界面特征、intersects_space、direct_access_to限定；负例检查
- **验证边界：**相交关系尚无真实实例；方向、容差和时点须实际采集。

- **[BOT02](zotero://open-pdf/library/items/6XP3U4GG?page=9)** BOT: The building topology ontology of the W3C linked building data group，2021；PDF 9／印刷 150，§3.3。原文支持：containsZone表示包含且具传递性；adjacentZone表示共享部分边界且对称；intersectsZone表示三维空间范围部分共享。 限度：不从邻接推导通行；不把所有本地关系直接宣告为BOT等价属性。
- **[BOT03](zotero://open-pdf/library/items/6XP3U4GG?page=10)** BOT: The building topology ontology of the W3C linked building data group，2021；PDF 10／印刷 151，§3.5。原文支持：Interface用于细述空间、构件及二者之间的关系，可附加空间之间通行类型与限制；interfaceOf关联相应对象。 限度：Interface不限于通行开口，也不等于墙或门实体。
- **[ISM03](zotero://open-pdf/library/items/5X32QFZG?page=10)** Development of an Indoor Space Semantic Model and Its Implementation as an IndoorGML Extension，2019；PDF 10／印刷 10，§3.2.1。原文支持：Pseudo opening没有实体框架，可以是墙上缺口，也可以产生于空间细分；开口记录连接空间、状态及可达限制。 限度：无门框不自动证明任何人或任何时点可通行；堂屋—前廊是本研究的迁移示例。

### O04 名称、用途、围合与形态分轴

- **原状：**已有名称/用途/形态，但围合程度和多值约束不明确。
- **本轮改动：**保留原词，补围合程度、层位；用途明确允许多值，不强制唯一总类型。
- **转换理由（研究者判断）：**前廊可同时是名称、半开放空间及交通/停留场所。
- **实现位置：**features与示例两个space_use断言
- **验证边界：**不把徽州类别直接认作景宁地方分类，也不把Hall译作堂屋。

- **[H04](zotero://open-pdf/library/items/9TUEWX22?page=1)** 地域性民居风貌要素语义体系构筑方法及特征解析——以徽州地区为例，2019；PDF 1／印刷 94，研究操作。原文支持：将空间、图案、样式等形式转为专业描述语汇，再梳理概念间逻辑关系；正文第2页补充先提取构成、形式、类型、组合、材质、色彩并制作对应图示。

### O05 术语对齐与实体去重分开

- **原状：**仅以文字说明保留原词与源内身份，缺少结构化对应规则。
- **本轮改动：**增加词表与映射状态、实体身份核对契约；相近词不自动合并建筑。
- **转换理由（研究者判断）：**便于跨文献比较，同时保留不同地域、文献的用词差异。
- **实现位置：**vocabulary两条来源用语；entityAlignmentContract
- **验证边界：**未开展全库词汇归并或跨文献建筑去重；Hall与堂屋禁止自动等同。

### O06 明确概念、实例、组成和属性的落位
