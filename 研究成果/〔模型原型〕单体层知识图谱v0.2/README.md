# 单体层知识图谱 v0.2：空间语义与研究追溯优化

本版依据用户提供的[知识图谱文献拆解入口](../../文献库/文献导图/知识图谱文献拆解/README.md)，结合 BOT（2021）及室内空间语义模型（2019），在 v0.1 上完成十项优化。模型和字段属于本研究的综合设计；已完成的是结构、文献记录迁移、合成空间示例和查询检查，尚未完成景宁实地样本验证。

**建议先看 [十项优化及依据](优化清单与依据.md)，再打开 [图谱浏览](图谱浏览.html)。** 浏览图包含“概念”“文献案例”“空间演示”三种独立视图，并可逐项查看优化依据。可编辑的[优化导图](../〔讨论图示〕思维导图/单体层知识图谱v0.2/00-优化与依据.smm.md)用于讨论。

## 本版保留与新增

- 保留原文献案例的14个节点、27条断言、4次分类和未裁决来源冲突；没有补造真实房间、通行路线或三维锚点。
- 新增Interface、AnalysisRun两个概念，模型共有11类、30项特征、18类关系。
- “堂屋—前廊—卧室”是单独的合成演示：7节点、28断言，不对应某座实际住宅，不纳入真实样本数量。
- “相似分析”和“三维绑定”本轮完成记录契约及防错约束；未执行相似度/聚类，也未关联真实三维文件。
- v0.1目录和原文献拆解成果保留原样；每次检查会核对v0.1原文件哈希。新版是可回退的讨论与试建版本，不表示导师或用户已逐字段最终确认。

## 依据与事实如何回溯

**模型设计链：** 优化ID（O01—O10） → [优化记录](优化记录.json)中的前后差异与迁移理由 → [优化依据](优化依据.json)中的证据ID → 原文PDF页序、印刷页、章节/图表 → Zotero原页。方法论文只支持模型取舍，不能证明某座民居实际存在该空间或关系。

**建筑事实链：** 对象/关系 → [案例图谱](案例图谱.json)中的断言或分类判断 → 本数据集证据 → 来源及具体表行/图页。原型试判、作者解释、读者拆分与原表记载保持不同归属。原有屋面冲突不覆盖、不自动裁决。

**演示链：** [空间关系演示](空间关系演示.json) → 虚构设定E_DEMO。它只能证明程序如何处理这组输入，不构成论文或现场事实。

**变更链：** [研究过程记录](研究过程记录.md)说明本轮实际工作与未完成范围；[模型差异记录](模型差异记录.json)保存机器模型的前后值；[迁移记录](迁移记录.json)保存原文件哈希及允许变化；[程序核验](查询与验收.md)重算事实保留与查询结果；[原文抽核](原文抽核记录.md)和[独立验收](独立验收.md)分别说明实际检查范围。

## 当前维护入口

- `模型定义.json`是机器可读模型的维护源；`优化记录.json`记录具体变更；`优化依据.json`记录证据，不另复制论文完整框架。
- `案例图谱.json`是文献试表达数据；`空间关系演示.json`是独立教学输入。
- `生成浏览图.py`从五份输入生成自包含HTML；`检查图谱.py`生成验证结果、查询报告和模型差异记录。修改输入后须依次运行检查与生成器。
- 原生导图是可编辑讨论视图，不自动回写JSON；其中的新意见需经核对后落实到模型维护源，再刷新视图。

运行方式：在本目录执行 `python3 检查图谱.py`，随后 `python3 生成浏览图.py`。不需要安装图数据库。
