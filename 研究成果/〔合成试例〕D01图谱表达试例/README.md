# D01图谱表达：统一原型的分析入口

**本包不再维护一套独立活动实例。** 尺寸直接归对象、字段来源与共同基准、檐口高差比较已接续到[[研究成果/〔合成试例〕虚拟民居单体试验V01/README.md|统一原型入口]]；已迁移并完成限定读回核验。请从[[研究成果/〔合成试例〕虚拟民居单体试验V01/审核视图.html|统一实体关系审核]]选择D01分析。

- 活动参数唯一维护在[[研究成果/〔合成试例〕虚拟民居单体试验V01/案例模型.json|V01案例模型]]；本包`案例模型.json`为明确转接记录，不含另一份节点／属性数据。
- 原D01主屋／院落角色接续V01:B01／S05；原D03外部分析复用S04／S05／S06、I04／I05及已存在院墙／柱。异例角色对应不是实体sameAs，旧数值不直接覆盖V01。
- 本包原始模型、页面及证据保存在[[archive/2026-10-30-统一原型合并前/README.md|合并前原件与恢复]]；其历史核验仍有效于旧版本，不能充当当前统一迁移验收。
- [[研究成果/〔类型图谱〕建筑空间界面与构成关系类型图谱/类型图谱.md|关系模式与原型覆盖]]说明原型可展示的模式与归档变体。详细数据拆解表与原生导图仍在[[研究成果/〔分析框架〕风貌分析拆解/README.md|风貌分析拆解]]维护，不被这一转接替代。

## 保留与未覆盖

D01只接续既有最小尺寸／比较链，不声称全部六项完成。D03六项在同一原型上表达，但双院、单向、关键未知与多用途等旧变体留回归夹具；不为覆盖它们补造第二院或用途。

用户认可过原表达思路与D03首例，不等于本次新增参数、投影、面积口径已获语义批准。内部构架、完整室内／跨层网、时序与感知不恢复；真实有效性未验证，合成试例不进正文或默认附录。

旧`Neo4j/`目录下回执保留历史日期；当前库状态、实际查询及恢复只看[[研究成果/〔合成试例〕虚拟民居单体试验V01/Neo4j/README.md|统一数据库入口]]。旧执行器不再作为活动入口，其模型校验会拒绝转接文件；不会自动恢复旧dataset。
