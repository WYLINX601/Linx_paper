# 综合依据与范围取舍

本文件解释研究者怎样从既有成果组织本轮框架。它不是作者原框架图，也不表示文献共同验证了这套分类。

## 两组成果怎样互补

| 分析问题 | 类型学／形态学成果提供什么 | 夏雷提供什么 | 本轮处理 |
|---|---|---|---|
| 拆成什么对象 | 主附构形、合院细胞、功能空间、侧样构架、立面及地块等不同单位 | 宅院、单体、构件、住户和资料分组 | 按具体对象保存，空间与实体部分均保留；户与栋不互换 |
| 如何描述形态 | 轮廓、进跨、轴线、围合、比例、构架、天际线与切片 | 材料、形式、颜色、尺度及人工风貌信息 | 分清对象、维度和类型取值，补足外观细部 |
| 如何描述联系 | 平面组合、空间通行、构架支承、内外形态对应 | 庭院布局、生活流线、建筑与街道／环境联系 | 空间组织、物理构造及活动关系分别记录 |
| 如何比较 | 判据、原型与变体、几何量化、样本分类及共时历时 | 编码、资料整理、候选筛选和指标区分 | 借鉴研究过程，保留分类体系与分母，不照搬阈值 |
| 如何解释 | 材料环境、备料、礼制、家庭变化等作者解释 | 季节用途、人口收入、地方感知、东北适应性解释 | 将解释关联具体对象与来源，保留假设身份 |

## 不可直接等同的术语

| 来源术语 | 本轮对应方式 | 不直接等同什么 |
|---|---|---|
| 三间张、五间张 | 保留来源的平面及组合定义 | 不能只换成房间数；与三开间仅部分重叠 |
| 堂屋、顶厅、火塘屋、客厅 | 地方名称与实际用途分别保存 | 不能统一替换成同一个功能类别 |
| 合院细胞、庭院、天井、后厨天井 | 先注明对象边界和层级 | 不能都作整栋平面类型 |
| 构架、梁架、屋顶、屋面 | 保存原图原词、正文用词及本研究对齐说明 | 不能声称来源全部使用同一套术语 |
| 空间结构 | 夏雷语境主要是组织关系 | 不等同木构受力结构 |
| 原型、基本型、通用型、常见型 | 保存作者定义、推辨依据或频数分母 | 众数不等于原型；形态变体不等于历史谱系 |
| 质量、遗存度、传承度 | 保存对象、时点及判据 | 单栋状态、村落评价与结构安全鉴定不同 |

## 尚待深化的覆盖缺口

- **营造细节**：B508、B511、B512、B621需要续读营造章节与节点资料；已有框架不能提供所有榫卯、工序、分水判据。
- **装饰与文化解释**：B617、B806、B807需要部位明确的图像、工艺或口述证据；图案题材不自动证明含义及民族独有性。
- **环境性能**：B803先保存空间和开口线索。照度、温湿度、通风等若作为实测研究，需独立协议、时段及仪器记录。
- **时序与真实关联**：B701—B706需要同一对象的前后资料；三维数据与对象匹配仍属后续方法，不是夏雷框架自动提供的结果。
- **资料与分类重复性**：空间边界、主附关系、缺损形态、多用途及混合构架需试采，检查不同记录者能否得到一致判断。

本轮的完整性检查是“范围有交代、相关维度有位置、未知和暂缓内容有记录”。它不是统计意义的穷尽证明。
