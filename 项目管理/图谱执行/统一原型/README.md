# 统一原型执行入口

活动主源为[[研究成果/〔合成试例〕虚拟民居单体试验V01/案例模型.json]]，当前V01-unified-2.2；数据库及审核页为其投影。合成固定原型，不是自动同步服务或通用规则引擎。

## 维护入口

使用academic Python运行本目录`check.py`。默认将正式主源、执行模块、夹具和必要归档下载到独立scratch后运行218项检查，不写Paper、不连接数据库。`--database`增加既有SSH-backed MCP的逐属性、原生类型、26组查询及正式页候选重建，仍不执行导入或发布。实跑范围见[[研究成果/〔合成试例〕虚拟民居单体试验V01/Neo4j/基础关系修订验收.md|验收]]；未提供真实读回时两项等值测试会明确跳过，不能算通过。

`--candidate-root`仅供隔离验收，不得指向Paper。`tools/semantics.py`维护局部边界与派生、角色／端点／字段来源义务；`projection.py`从实际LPG重建，缺失不回退rawModel。`test_semantics.py`包含56项基础关系／本轮修复测试，`test_review_fixes.py`保留2.1修复回归。
