# 论文精读卡片使用说明

## 已确认的工作规则

用户确认以提供的 `nature-paper-card` 为基础适配本研究，并明确：**后续涉及论文阅读，都先创建或复用精读论文卡片，再进行处理，便于后续复用。**

执行顺序：

1. **查同篇**：按DOI、Zotero父条目、已核题名作者查已有卡片；同篇已有卡直接复用。
2. **无卡先建**：先保存来源、已知题录、材料范围和未读部分，标明Partial；只是登记，不是提前宣称精读完成。
3. **按任务核读并补卡**：完整精读、方法/理论/章节核读都更新同一份卡；定向任务不擅自扩大为全文。
4. **再处理**：方法拆解、跨篇比较、写作引用或阅读导图以卡片和原文证据为基础，新增认识先回写卡片。
5. **持续复用**：下次按问题读取相关卡片章节与原文定位，不重复建卡或无差别重读。

卡片记录的是作者论文及阅读判断，不是本研究已采用的规则。初读、局部精读、精读、脚本检查与用户认可分别说明；暂缓的研究问题映射不会为了填卡而补齐。

## 技能怎样分工

| 入口 | 职责 |
|---|---|
| `nature-paper-card` | 新卡与卡片先行流程；16节中文合同、来源准备、证据链、审计与Paper归位 |
| `read-research-paper` | 共用阅读证据规则、贡献分类、定向阅读及旧笔记兼容更新 |
| `paper-methods-comparison` | 每篇先卡后读，保持逐篇讨论节奏，再对齐与综合 |
| `obsidian-mindmap` | 按需生成可编辑阅读视图，不增加独立论文或证据数量 |
| ARS | 研究任务路由、阶段合同与授权；本卡片是本地专业扩展，不是新增上游官方模式 |

无需记住技能名。今后说“读这篇论文的方法”“比较这几篇论文”“精读并做导图”，都会先查找或建立相应单篇卡。只有题录检索而没有开展论文核读时，不冒称已经精读；开始所选论文的阅读之前再按本规则落卡。

委派时由主会话先建/复用卡，并把路径、当前SHA和已读范围交给子agent；只读worker返回证据和候选更新，最终补卡由主会话保护写回。技能指令不是运行时权限沙箱，也不是任何模型必然遵守顺序的技术保证。

## 16节与建筑学适配

| 层次 | 内容 |
|---|---|
| 01—06 | 文献信息与范围、一句话概括、问题/对象/尺度、学术脉络、难点、核心思路与贡献 |
| 07—11 | 理论化用与研究路径、分析环节/分类判据、定义/公式、材料与主张—证据链、成果解释 |
| 12—13 | 作者明确自述的局限；阅读者分析、反例与待核问题，两者分开 |
| 14—16 | 可积累知识、对本研究的潜在用途与条件、后续问题及经请求才展开的候选设想 |

新增建筑调查/类型/空间研究和理论/框架两个分析视角；保留上游方法、发现、资源、临床、材料、综述视角。分析视角不替代贡献性质、研究方法、主题对象、出版体裁四维分类。

理论论文沿概念—命题—论据展开，调查论文沿观察—分类—比较—解释展开，不强制实验或消融。保留作者的正面成果、地方术语、类型判据和异例；照片数、侧样数、住户数与建筑数不混用。文献调查时点不能代表现状，外观不能单独证明民族属性、内部构架或文化因果。

未请求构思时，第16节写明不展开，不自动产生研究方案。已有卡片不必为了新模板重排；初建或局部阅读的未读栏目明确保留，不编造完整内容。

## 文件归位与唯一主记录

- 单篇主卡：`文献库/作者-年份-短题.md`；已有卡保持原路径、身份、批注和实际阅读范围。
- 支持文件：沿用既有专题证据目录，或用 `文献库/核读记录/<稳定短题或原有ID>/`，保存来源包、审计报告和必要核读记录。支持文件不标作另一篇论文。
- 原PDF：复用Zotero已有附件；父条目key、附件key、DOI及版本分别记录，不复制原始文献库。
- 导图与专题比较：回链卡片及原文。导图是阅读视图，不与卡片竞争论文事实维护权。
- 写回：通过 `mac-paper`，覆盖使用最新SHA，冲突重新读合并，新建用expect-missing；不手改文献目录生成区。

本轮在现行卷上默认原子新建失败，回读确认目标缺失后，使用当前桥接器帮助已列出的 `--expect-missing --create-mode recoverable`。该模式先保存恢复载荷，再排他创建并回读；**完整文件可见性不是原子的**，不能将其回执表述为原子新建。若结果不明，先读取目标和 `mac-paper recoveries 相对路径`，不重放已完成的批次。既有文件仍使用最新SHA、备份和原子替换。

来源包是可重建的解析副本，不是新的原始来源；分享时仍需检查论文许可与隐私。临时渲染与合成测试只在academic scratch，不进入文献库。完整阅读结构与真实读取范围独立记录。
