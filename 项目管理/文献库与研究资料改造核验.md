# 文献库与研究资料改造核验

> 本页是本轮“文献库—研究资料”结构改造的验收入口，不是研究结论页。检查对象是分层、索引、链接与字段读取，不判断论文真假、证据充分性或建筑数量。

## 一、文献库

### 改了什么

- 单篇笔记、专题精读、原生导图、获取／核读记录明确分层。
- `文献库/README.md` 中手工维护的 30 行状态表改为生成区；完整表移入 [[文献库/文献总索引.md|文献总索引]]。
- 新增 [[文献库/文献库维护规则.md|文献库维护规则]]，规定四类对象、最低字段、阅读状态、阅读范围、一源多视图和索引生成方式。
- 新增 [[文献库/专题精读/README.md|专题精读入口]]、[[文献库/文献导图/README.md|文献导图入口]]、[[文献库/核读记录/README.md|核读记录]]、[[文献库/文献获取/README.md|文献获取记录]]。
- 吴莹 2018 单篇笔记补 `read_scope` 与 `topics`，索引不再显示空的阅读范围。

### 当前计数

- 单篇与专题拆解：**30**
- 专题精读包：**4**
- 原生导图：**44**
- 文献库内相对链接：**354 条，0 缺失**

### 检查入口

- [[文献库/文献总索引.md|文献总索引]]：按年份列出阅读状态、阅读范围、Zotero／DOI 与关键词。
- [[文献库/README.md|文献库入口]]：生成摘要与分层链接。
- `python 项目管理/健康检查/literature_views.py --check`：应输出 `out_of_sync: []`。

## 二、研究资料

### 改了什么

- 明确四类：来源证据、村落资料、对象候选、文献证据汇总。
- 新增 [[研究资料/资料总索引.md|资料总索引]]，按类别和分村列出入口、文件构成与边界。
- 新增 [[研究资料/资料维护规则.md|资料维护规则]]，规定来源、时点、文件数与对象数的区分。
- 新增 [[研究资料/对象候选/README.md|对象候选入口]]、[[研究资料/文献证据汇总/README.md|文献证据汇总入口]]，明确“候选不是正式样本”“记录条数不是建筑数”。
- 为外部 Wiki 技能快照增加 [[研究资料/来源证据/2026-10-28-研究Wiki技能参考/README.md|边界说明]]：工具参考，不是研究证据或本库指令。

### 当前计数

- 分村资料：**2**（敕木山、大张坑）
- 研究资料内活动相对链接：**798 条，0 缺失**

- [[研究资料/README.md|研究资料入口]]：生成摘要。
- `python 项目管理/健康检查/materials_views.py --check`：应输出 `out_of_sync: []`。

## 三、没有做的事

- 没有重新精读论文、没有核验 Zotero 全库、没有重做图像分析或现场调查。
- 没有移动、删除或重命名原始资料、单篇笔记、专题包和导图。
- 没有修改 BOT 双基准、案例 JSON、模型、CSV、Neo4j 或章节采用关系。
- 没有把文件数、图像数、专题页数当作论文数、建筑数或独立证据数。

## 四、验收清单

- [ ] 文献库 README 不再手工维护 30 行状态表，改为生成区并指向总索引。
- [ ] 单篇笔记、专题包、导图、获取／核读记录四类入口可区分。
- [ ] 研究资料四类入口可区分，分村资料能从总索引进入。
- [ ] 对象候选和文献汇总页都写明“不是正式样本／不是2026现状”。
- [ ] 外部技能快照被标为工具参考，而非研究证据。
- [ ] 两个生成器 `--check` 均为 `out_of_sync: []`。
