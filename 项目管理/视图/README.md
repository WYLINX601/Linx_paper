# 研究论证只读视图

[Bases视图](研究论证.base)读取主题、子问题、论点页的 frontmatter，提供四个筛选：

- **子问题**：按所属主题、逻辑作用、状态查看；
- **论点**：按主题分组，查看性质与状态；
- **待复核**：只显示 `candidate` 或 `contested` 论点；
- **主题**：查看研究角色与状态。

## 使用边界

- 数据主源仍是各主题页、问题页和论点页，Bases只读不写，不另存一份研究内容。
- 不在视图中直接修改属性；需要变更时回到对应页面，再用 `research_claims.py` 同步派生块。
- 视图不判断研究真假，也不替代章节采用关系、证据核验或数据库查询。
- 字段变化时先改页面 frontmatter，再调整本视图的列；不新增手工维护的第二套索引。
## 验收

2026-11-04已在Obsidian实际打开`研究论证.base`：子问题视图显示15条结果，列包含页面、所属主题、逻辑作用、状态、摘要，无报错。所属主题、逻辑作用、性质、状态、摘要等展示列使用公式副本，避免在视图中直接改属性；文件名仍保留可点击链接。其余视图由同一YAML定义，未逐一截图。
