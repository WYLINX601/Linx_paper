## 执行材料与恢复

`生成四村原生画布.md`及`编排数据.json`保留本轮生成方法和输入快照；`查看全图.md`仅调整显式目标view，不保存图源。不要把冻结输入当作自动同步的现行村落主表，也不要直接重跑来覆盖用户后续编辑；继续整理必须先重读现行图源、主源和最新SHA。

首轮候选与修订候选已在正式文件验收后移入Obsidian回收站，研究资料目录不保留第二张候选主图；本目录PNG为过程排版检查，不是新的正式版本。正式原件备份及源哈希见结构化记录。

实现中确认：`excalidraw-autoexport`必须使用`none`等文本枚举，不能用布尔`false`；`source=disk`导出不能同时指定view；固定宽文本需在布局前按插件字体测量明确换行。遇到未知结果先查回执和读回，不重跑生成覆盖。
