# 成果分层与递进关系核验

> 本页是本轮结构改动的验收入口，不是研究结论页。检查对象是成果层级、成果递进关系与派生视图，不判断研究真假、实证完成度或数据库状态。

## 本轮改了什么

- 22 个成果包 README 增加 `artifact_group`，按六层分组：现行主源 9、现行候选 2、过程原型 4、统一原型入口 2、展示与讨论 3、文献核查记录 2。
- 3 条有明确依据的成果递进关系写入**后继包**的 `artifact_relations`，方向为后继→前置：

| 后继成果 | 关系 | 前置成果 |
|---|---|---|
| V01 统一原型 | 合并 | D01 图谱表达试例 |
| V01 统一原型 | 合并 | D03 院落围合图谱试例 |
| 方法衔接 v0.1 | 建立于 | 建筑单体研究内容框架 v0.1 |

- 成果包页、主题页和成果总目录中的关系表均由 `topic_artifact_views.py` 从 frontmatter 生成；没有在多个页面手工复制同一份关系。
