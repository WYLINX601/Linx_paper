# 论文章节维护

本目录保存章节结构维护文档，不保存正文。正文工作稿仍归 `全文工作稿/`；`章节导航/` 下的生成页是由大纲生成的章节工作台，不是第二份正文。

**2026-11-17 V3.3落库状态：** 现行大纲已按Notion V3.3改为建筑形态—本体—知识图谱—知识发现六章结构，1.1 V0.9、1.2 V0.3、1.4 V0.1、1.5 V0.1已进入新正文工作稿。`正文对齐检查.md`与`章节迁移映射.yaml`仍记录2026-11-05大纲对v0.6旧稿的对应关系，保留为旧定位施工记录，**不得当作V3.3章节与正文的现行映射**；1.3及第二至第六章的正文对齐待按V3.3重做。

## 入口

- [[论文章节/维护/目录维护检查.md|目录维护检查]]：六章结构、稳定 ID、路径、停用节点与正文接续检查。
- [[论文章节/维护/目录内容审阅.md|目录内容审阅]]：2026-11-04 第二轮内容审阅；保留六章与标题，记录已应用的论证边界和第三章待定结构。
- [[论文章节/维护/正文对齐检查.md|正文对齐检查]]：现行大纲与 v0.6 的章级差异、可接续与不可接续部分。
- [[论文章节/维护/章节迁移映射.md|章节迁移映射]]：v0.6 二级节到现行节的逐节施工图（由 YAML 生成）。
- `章节迁移映射.yaml`：迁移映射的维护主源，不手工改生成视图。

## 目录分工

| 位置 | 职责 | 不是什么 |
|---|---|---|
| `大纲结构.yaml` | 章目、节序、主题采用、证据要求的唯一主源 | 不是正文 |
| `现行大纲.md` | 由主源生成的单一总览 | 不是第二份结构主源 |
| `章节导航/0X-….md` | 每章的结构、主题入口、证据要求与稳定锚点 | 不是论文正文，不另写一份章节稿 |
| `全文工作稿/景宁畲族传统民居建筑形态知识组织与应用研究v0.1.md` | 当前1.1/1.2/1.4/1.5正文工作稿；1.3待写 | 不是现行结构主源，也不是完整六章稿 |
| `全文工作稿/…v0.6.md` | 2026-10-15旧定位正文，供引文定位与部分章节接续 | 不是当前正文主源，不能直接充当V3.3章节 |
| `维护/` | 目录检查、正文对齐、迁移映射 | 不是研究结论或正文 |
| `写作规范/` | 格式与证据说明 | 不是正文 |

## 维护规则

- 新增或调整章目、节序、停用/启用、主题采用：只改 `大纲结构.yaml`，再运行 `research_structure.py`。
- 章节导航中的生成区不手工改；需要改结构时回主源。
- 章节子目录已取消；不再新建“论文正文稿”“第二章正文稿”等第二份正文。需要按章写作时，统一放在 `全文工作稿/`，并明确版本与状态。
- 旧稿、试排稿和重复正文移入 `archive/`，保留原路径、SHA 与恢复说明，不作为当前主源。
- 目录检查、正文对齐、迁移映射只做结构与接续判断，不判断引文或研究结论。
