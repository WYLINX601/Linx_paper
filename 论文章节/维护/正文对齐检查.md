# 正文对齐检查

> 本页对照[[论文章节/大纲结构.yaml|大纲结构主源]]、[[论文章节/现行大纲.md|现行大纲]]与[[论文章节/全文工作稿/景宁畲族传统民居风貌特征提取与知识图谱构建研究v0.6.md|v0.6正文工作稿]]。它只检查章节职责、标题和可接续关系，不判断正文论证是否成立，也不改写正文。
>
> 逐节施工图见[[论文章节/维护/章节迁移映射.md|章节迁移映射]]；本页保留章级判断。

## 一、结论

- 现行大纲是**六章、35 个活动二级节、20 个三级节**；这是工作结构，不是定稿目录，也不表示正文已经完成。
- v0.6 仍是**旧定位的六章工作稿**，共 32 个二级标题；它的第一章、第三章至第六章可以按节接续，**第二章不能直接当作现行第二章使用**。
- 不需要为了“对齐”整体重写 v0.6。正确顺序是：先把现行章节职责固定，再逐章决定“保留、改写、移入其他章、停用追溯”，避免把旧稿的章节结构反向带回新大纲。

## 三、已经发生但容易被误读的结构变化

### 1. 第二章的职责换了

现行第二章从“研究对象与资料基础”改为“理论基础与研究框架”，回答四个问题：风貌是什么、怎样分析、知识图谱是什么、如何结合。旧稿第二章的对象、样本、资料内容不再属于现行第二章，主要接续到现行第四章的 4.1—4.3。

因此：

- **不要**把旧稿第二章整章搬进现行第二章；
- **不要**因为旧稿第二章有“研究对象”，就认为现行第二章缺少对象界定；对象界定在第一章 1.2 和第四章 4.1—4.3；
- 现行第二章需要的是概念辨析、理论比较、图谱基础和结合论证，这部分目前仍是缺口。

### 2. 第四章的节号来自旧稿，不是当前编号

现行第四章的活动节在 YAML 中保留了 `section-2-1`、`section-2-2`、`section-2-4` 等稳定 ID 和 `origin_number: 2.x`，表示它们从旧第二章迁来；但生成器按章内顺序显示为 **4.1—4.8**。`origin_number` 是溯源信息，不是当前节号。

同理，第二章里保留的 `section-3-1` 是已停用节点，不出现在现行大纲的 2.x 列表中；它的存在只用于追溯，不表示第二章还有 3.1。

### 3. 章节导航已扁平化，旧目录名不再作为当前路径

`02-研究对象与资料基础`、`04-案例实施与检验` 是早期目录名；2026-11-04 已将六章导航扁平化为 `论文章节/章节导航/01-绪论.md` 至 `06-结论.md`，六个章节目录已删除。当前章名以大纲主源的 `title` 为准，旧目录名只保留在归档快照和历史映射中。若以后确需改名，仍须单独迁移、修复引用并保留恢复映射。

## 五、建议的下一步

1. **先确认现行六章职责不再变**，再开始逐章改写；否则旧稿会被反复搬动。
2. **先处理第一章和第二章**：第一章建立问题与范围，第二章补概念、理论、图谱基础与结合论证；这两章决定后续三章的论证链。
3. **第三章到第五章按“体系—实例—分析”顺序改写**，不把旧稿的“对象与资料章”插回第二章。
4. 每章改写前，先从[[主题研究/README.md|主题研究]]和[[项目管理/研究论证索引.md|研究论证索引]]取当前判断与依据，不从 v0.6 的旧结论反推。
5. 本页只做结构对照；正文改写、引文核对和实证判断另行验收。
