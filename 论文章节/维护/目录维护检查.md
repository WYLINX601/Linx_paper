## 二、本轮修正

### 1. 第二章的正文接续指向错误

原 `chapter-2.body_source` 指向 v0.6 第二章“景宁畲族传统民居研究对象与多尺度资料基础”。这会让第二章导航显示“打开既有正文对应章”，但打开的是已经被迁移到第四章的对象与资料内容，容易把旧第二章误当现行第二章草稿。

已改为：

- `body_source: null`
- `body_note: 旧稿第二章……已按迁移映射进入现行第四章；本章（理论基础与研究框架）无直接旧稿，需新写。`

第二章导航现在显示“正文接续：旧稿第二章……无直接旧稿，需新写”，不再生成错误的正文链接。生成器也已支持 `body_source: null`，并要求每章至少有 `body_source` 或 `body_note`。

### 2. 停用节点的接续说明

`section-3-1`（研究框架与体系、图谱及分析的衔接）是第二章中的停用节点，原先没有 `superseded_by`。已补：

```yaml
superseded_by:
- section-2-integration-framework
```

表示其“总体框架”职责由现行 2.4 接续。`section-4-synthetic` 保持无后继：合成试建属于正文外过程材料，不设正文节替代。

## 三、不是错误、但需要理解的编号现象

### 1. 稳定 ID 与显示编号不同

生成器按**当前章内顺序**重新编号；`section-2-1`、`section-3-2` 等稳定 ID 不随显示编号变化。例如：

- 第一章 YAML 顺序是 `1.1 → 1.3 → 1.4 → 1.2 → 1.5 → 1.6`，显示为连续的 1.1—1.6；这是有意调整“对象范围”和“研究问题”的顺序。
- 第三章第一个活动节点是 `section-3-2`，显示为 3.1；`section-3-1` 是停用节点。
- 第四章的活动节保留 `section-2-1`、`section-2-2`、`section-2-4` 等 ID，显示为 4.1—4.8；它们从旧第二章迁来，`origin_number: 2.x` 只作溯源。

**规则：看显示编号，认稳定 ID；改顺序只改 YAML，不重命名 ID。**

### 2. 目录名是历史路径

旧章节目录名 `02-研究对象与资料基础`、`04-案例实施与检验` 已随本轮扁平化取消；新导航文件按章命名为 `章节导航/02-理论基础.md`、`04-景宁实例.md`。旧目录名只保留在归档快照与历史映射中，不再作为当前路径。

如果以后确需重命名，必须单独做迁移：改目录、改 `path`、修所有引用、保留恢复映射，不能只改文件夹名。

## 五、维护规则

1. 章目、节序、活动/停用状态、主题采用只改 `大纲结构.yaml`；不要手工改章节导航中的生成区。
2. 失效节点用 `included: false` 保留，不删除；能明确接续的写 `superseded_by`，没有正文替代的写清原因。
3. 新增章节或节时保留稳定 ID；显示编号由生成器按当前顺序计算，不把 `origin_number` 当现行编号。
4. 目录名、正文锚点和旧稿路径分离管理；改路径必须单独迁移，不把“改标题”与“移动文件”混在一次操作里。
5. 正文改写前先核对[[论文章节/维护/正文对齐检查.md|正文对齐检查]]和[[论文章节/维护/章节迁移映射.md|章节迁移映射]]，不从旧稿第二章反推现行第二章。
6. 每次改动后运行 `research_structure.py --check`；本页只记录结构维护，不作为研究完成或正文验收。
