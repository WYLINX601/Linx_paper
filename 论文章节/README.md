# 论文研究工作台

**日常从章节进入研究，从主题进入成果，从成果回到依据。**

**目录分工：** `大纲结构.yaml`（结构主源） · `现行大纲.md`（单一总览） · `章节导航/0X-….md`（章节工作台，不是正文） · `全文工作稿/v0.6.md`（唯一旧正文） · `维护/`（目录检查与迁移映射）。不在章节目录下另建第二份正文稿。

**直观看目录：** [[论文章节/论文目录.smm.md|原生可编辑思维导图]]。由现行大纲派生，保留当前手工展示编辑与样式；三级可按需展开，节点链接进入对应章节工作台。当前图中2.1及其子节点未展示，本轮未擅自恢复，也未据此改动大纲；完整章目以现行大纲为准。章目仍在`大纲结构.yaml`唯一维护，调整后须显式同步本图；当前尚未接入`paper-maintain sync`自动生成，不另作手工目录主源。

**直观看研究框架：** [[研究成果/〔研究路线〕论文研究路径/README.md#论文研究框架图（待审核首稿）|黑白竖版研究框架图]]，按六章表现“研究基础—体系与方法—实例应用与认识—综合归纳”；包含可编辑图源及图片，作为派生展示，不改动目录、正文或研究状态。
