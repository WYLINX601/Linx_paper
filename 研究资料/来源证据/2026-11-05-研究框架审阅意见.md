# 研究框架审阅意见原文

来源为用户本轮粘贴附件；作者及生成工具未标。以下原文逐字保留，不把全文评价当作已确认研究事实。用户后来确认的是主会话核对后的最小限定方案，见[[context/PROJECT_CONTEXT.md#研究框架限定依赖与最小修订（2026-11-05，用户确认）|已确认范围]]。

<!-- original:start -->
我看完了这张框架图。整体评价是：这版已经形成比较完整的论文论证结构，六章之间的关系基本清晰，没有必要再进行大的结构调整。

尤其是第三章、第四章已经从原来的多个并列操作环节，调整成了体系设计、模型构建、实例应用和成果检验几个层次。第五章取消5.1之后，分析也更加直接。

但如果从严格的学术逻辑来看，我认为还有 4处值得优化。其中第一处最重要。

## 一、整体逻辑：已经形成完整的递进关系

先看整篇论文。

第1章 绪论

提出研究问题，明确研究对象与目标

第2章 理论基础与研究框架

建立风貌分析与知识图谱结合的理论依据

第3章 体系与方法

建立多尺度特征体系、知识图谱模型和分析方法

第4章 实例构建

将理论体系应用于景宁真实民居资料

第5章 风貌分析

通过实例图谱形成多尺度建筑学认识

第6章 结论与展望

总结研究成果、贡献及适用范围

这条主线是成立的。

我认为最值得保留的是第三、四、五章的职责划分：

- 第三章研究如何建立一套认识民居风貌的体系。
- 第四章研究如何把这套体系应用于真实民居。
- 第五章研究通过这套体系，究竟能够认识到什么。

这三章分别对应方法设计、实例应用和知识发现，不应该相互混淆。

## 二、第三章：有一处需要进一步理顺内部关系

建议重点调整

你现在的第三章是：

- 3.1 风貌特征体系的构建依据与原则
- 3.2 多尺度风貌特征体系及其知识表达
- 3.3 知识图谱模型与构建方法
- 3.4 风貌类型识别与比较分析方法

这个结构已经比较合理。

但看你的框架图，3.3和3.4是从3.2分别向下分出的两个并列模块。

我认为这里存在一个小的逻辑问题。

类型识别与比较分析，实际上需要以特征记录和知识组织为基础。

也就是说，两者虽然都是第三章的方法内容，但存在一定的前后依赖关系：

1. 3.2明确观察对象和特征内容。
2. 3.3建立统一的知识表达与关联模型。
3. 3.4利用前面形成的结构化特征，建立类型识别和比较方法。

因此，我建议调整框架图的箭头关系：

3.2 多尺度风貌特征体系及其知识表达

明确研究对象、特征与关系

3.3 知识图谱模型与构建方法

知识组织、跨尺度关联、三维关联与质量规则

3.4 风貌类型识别与比较分析方法

从结构化记录形成类型及比较规则

这样，3.4就不是一个独立于图谱构建的分析方法，而是建立在前面体系和模型之上的分析方法。

另外，我建议对3.3的三级标题做一个小调整：

- 3.3.1 图谱总体结构与跨尺度知识关联
- 3.3.2 语义对象与三维空间区域关联
- 3.3.3 图谱实例化与数据质量控制

其中3.3.3最好明确为实例化规则与质量控制方法，避免与第四章真实实例图谱的实际构建重复。

## 三、第四章：结构合理，但需要区分资料生产与图谱构建

你现在的第四章：

1. 研究区域与样本确定
2. 多源资料采集与风貌特征提取
3. 实例图谱构建与三维空间关联
4. 图谱构建成果与质量检验

我认为这个结构是正确的。

它实际上对应一条完整的数据生产链：

研究对象 → 原始资料 → 特征数据 → 图谱实例 → 成果检验。

不过，有一个值得注意的地方。

### 4.2与4.3的分工需要明确

4.2是把真实民居转化为可以使用的特征数据。

4.3是把这些特征数据组织为知识图谱，并与三维空间建立关联。

这两个环节的界限非常重要。

例如：

- 通过照片识别建筑的屋顶形态：4.2。
- 判断屋顶特征属于哪种类型：根据实际工作安排，属于4.2的标注或4.3的规则应用，但应统一口径。
- 将屋顶实体、建筑实体及其关系写入图谱：4.3。
- 将屋顶实体对应到三维模型中的具体空间区域：4.3。

这里建议在4.2.2中明确特征标注是否包含类型归类，避免第四章和第五章重复进行类型判定。

### 还有一个小建议

4.4目前写的是：

> 图谱构建成果与质量检验

这个标题很好。建议继续保留。

但内部应区分三个方面：

- 图谱结构与实际覆盖情况。
- 实例数据及关系的质量。
- 数据能够支持的分析任务与使用边界。

不要在这里提前写出第五章的风貌分析结论。

## 四、第五章：整体很好，我只建议调整一个表述

你现在的第五章是：

- 村落尺度的民居分布与环境关系
- 组团尺度的民居组合与街巷空间
- 单体尺度的民居类型与建筑特征
- 跨尺度风貌关联与综合特征
- 知识图谱与三维关联方法的应用评价

这部分我基本赞同。

尤其是没有再设置一个独立的分析任务章节。三个尺度直接展开分析，逻辑更加紧凑。

不过，我认为5.4的表述还可以进一步加强。

现在写的是：

跨尺度风貌关联与综合特征

框架图中进一步补充了：

类型组合—空间关系—有据的建筑学解释

我更倾向于把后者体现到正式标题中：

5.4 跨尺度风貌关联与综合特征分析

内部重点突出：

- 不同尺度特征之间的关联。
- 民居类型与空间组合的对应关系。
- 共性、差异与典型变体。
- 基于证据的建筑学解释。

这样，5.4就不仅是三个尺度的汇总，而是整个论文建筑学认识的集中体现。

另外，5.5的方法评价应当放在5.4之后。你现在的安排是正确的：先形成建筑学认识，再评价图谱和三维关联对认识形成的支持作用。

## 五、我认为还需要检查两个跨章节问题

这两点不是必须改标题，但对论文最终质量很重要。

第一，第二章与第三章之间是否存在理论和方法重复？

第二章2.4已经形成了“风貌分析与知识图谱结合的研究框架”。

第三章则进一步构建特征体系和图谱模型。

两者应当有明确区别：

- 第二章：论证为什么这样研究，以及总体研究框架是什么。
- 第三章：具体建立什么体系，采用什么规则和方法。

第二章不能提前写出完整的特征分类表和图谱模型。

第二，第三章与第五章之间是否存在方法和结论重复？

这是论文写作中更容易出现的问题。

- 第三章的类型识别，是提出分类依据与判别规则。
- 第五章的类型分析，是把这些规则应用于真实样本，得出实际类型和差异。

第三章不能提前出现景宁民居有哪些类型的实证结论；第五章也不需要重新介绍完整的类型识别方法。

## 六、最终修改建议汇总

我不建议再对整张图进行大规模调整。以下是我认为值得落实的修改：

| 位置         | 当前情况          | 建议                |
| ---------- | ------------- | ----------------- |
| 第三章3.3与3.4 | 图中呈并列分支       | 调整为有前后依赖的递进关系     |
| 3.3.3      | 图谱实例化与数据质量控制  | 明确为实例化规则与质量控制方法   |
| 第四章4.2与4.3 | 资料提取和图谱构建     | 明确特征标注与图谱实例化的分工   |
| 第五章5.4     | 跨尺度风貌关联与综合特征  | 改为跨尺度风貌关联与综合特征分析  |
| 第二章与第三章    | 理论框架与具体方法     | 写作时明确理论依据和操作方法的区别 |
| 第三章与第五章    | 类型识别方法与实际类型分析 | 明确规则设计和实证结论的区别    |

我的最终判断：这版框架可以作为下一阶段的论文工作框架，不需要再继续增加二级章节。

还有一个我认为值得坚持的原则：不要为了体现知识图谱的技术复杂度，不断增加图谱构建的章节。你的论文最终研究的是景宁畲族传统民居风貌，知识图谱是组织、关联和分析建筑知识的研究方法与成果载体。

论文的核心价值仍然应该落在：通过系统化的特征认识与知识组织，获得过去较为零散的建筑资料难以直接呈现的民居类型、空间组合及跨尺度风貌认识。
