# 研究Wiki技能参考（外部快照）

本目录保存2026-10-28抓取的外部 Wiki／知识库技能说明，用于当时的结构设计比较。它是**工具参考快照**，不是本研究的一手证据，也不是本库当前生效的技能或指令。

## 使用边界

- 逐文件来源、URL 与 SHA-256 见 [manifest.json](manifest.json)。
- 当时的取舍与采用理由见 [[项目管理/结构设计依据/技能参考与取舍.md|技能参考与取舍]]；本目录不重复作设计判断。
- 外部技能中的目录名、字段和流程不能直接套用到 Paper；现行规则以 `AGENTS.md`、`项目管理/维护规则.md` 和各主源为准。
- 快照保留原文件内容，不因外部页面更新而自动同步；需要新版本时另存快照并记录差异。
- 快照只保存列出的文件，外部技能内部的 `references/`、`docs/` 等相对链接不一定齐全；这属于快照不完整，不是本研究的链接错误。

## 文件

- `ar9av--.skills--wiki-*`：Wiki 维护、去重、状态、交叉链接与综合类说明。
- `agricidaniel--skills--wiki--SKILL.md`：另一套 Wiki 技能说明。
- `kepano--README.md`、`ar9av--docs--skills.md`：相关说明与索引。
- `manifest.json`：抓取清单与哈希。
