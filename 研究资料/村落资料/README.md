## 研究用途与阶段边界

> 以景宁畲族传统民居建筑及其聚居风貌为核心研究对象，构建多尺度语义描述模型，建立风貌对象、特征及关系与三维空间区域之间的关联方法，并通过案例标注、空间查询与风貌比较分析验证其有效性。

上引表述来自当前项目context，接续10月19日的方法目标与10月20日的对象聚焦。研究核心是语义描述模型＋三维空间关联方法；知识图谱是知识组织／查询实现载体；案例标注、空间查询与风貌比较分析为后续验证。**10月20日本次工作为目录盘点与收集清单设计，未开展新采集、建模或外部调研。**后续再以资料分析与试建检验可达程度、优化模型和方法，不将计划当成果。

用户附件将倾斜摄影村落实景三维模型作为核心资料方向，但具体村落、文件位置、照片／位姿／点云／工程／坐标与可用性未核验。村落—组团—单体（构件为单体内部层）仅为待检验起点，不擅自扩大成全覆盖；旧32项候选和虚构图谱原型不是已验证方案。

## 取用规则

- 优先由分村索引进入原证据，不移动、删改或以工作摘录替代原始资料；原始PDF仍以Zotero为准。
- 文献事实、网络记录与本轮整理判断分开；保留来源、页码／图号、调查／发布日期、对象对应程度及缺失状态。概述不冒充逐字引文。
- 证据条数、图片数、候选实体组数、住户数、建筑编号、样本数及建筑栋数分别记录，不能直接相加或替代当前存量。
- 文献历史状态不等于2026现状；图像不独立证明当前存在、民族专属性、年代或营造关系。关联候选不直接升级为同一实体。
- 原材料中的姓名、编号与地名按来源保留；不足以确认单体或三维区域对应的材料，明确标记缺口，不补造坐标或实体编号。
