## 本轮核读覆盖

本批复核地方官方网页（2022村落/四幢概述、2026年度文保单位名录、2015年保护范围批复正文）、Zotero景宁检索结果及原文PDF（2006地名歧义、2008东弄调研、2013图注、2025柴一涵论文指定页），并取得张云、都铭2025年《城市规划》敕木山专题原刊两页全文。每条引用保留发布日期、调查/拍摄日期（未载则明确标未载）、页码与图号。

2025原刊称村落畲族人口达97%、以蓝姓为主；约50栋是文章时点的村落建筑概述，不能等同2026现存传统民居数或省保“四幢”。文章称平均海拔约700m，入口至西北最高宅基地高差82m，三溪和树状水脉；文章描述的大多数住宅类型不能分摊给每栋。2018 Sohu报道称县城西南13km、海拔700m并“辖两个自然村”；2022官方网页称县城东南约5km；2025原刊称西南约6km、平均海拔约700m。距离、方向、辖区和海拔口径均按原来源并列保留，不能当作互相验证或统一现状。原刊正文没有可确认的印刷页码；首页所见“遗珠拾粹253”为栏目标识，不作页码。索引按PDF p1—2定位，书目页码按题录记49(02):133-134。

“蓝姓族长的四合院民居”是2025原刊图注/正文中的候选对象；不得据此与蓝文成家、2019报道的史图博旧居、2013年“28号”或“蓝村长家门楼”、展馆旧宅或省保四幢合并。2006/2008“敕木山东弄”资料已核为东弄村语境，不纳入本村建筑证据。

## 边界与待补材料

本批是来源和历史材料整理，没有新增本组现场踏勘、逐栋测绘、建筑现状检查、持有人访谈或可用三维模型。父任务对常见本机入口/模型扩展名的排查在共享记录中说明其范围；未找到不等于资料不存在。CMS-M001所述四幢是集合描述，CMS-M008“约50栋”是不同来源、不同统计口径，均不能直接生成建筑唯一ID。

2015批复附件CEB普通下载返回“禁止访问”；取得后再核保护范围，不根据正文或照片推绘边界。公开网页与论文图像保留署名/水印信息，转载授权仍需按具体用途核对。原PDF及网页快照均保留在批次目录，Zotero原件未移动/覆盖。
