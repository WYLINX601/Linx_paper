# 研究资料维护规则

本页规定研究资料“放在哪、怎样记来源与时间、什么不能从文件数推断”。它不判断资料真伪或研究价值，也不替代 Zotero、村落索引或主题判断。

## 一、四类资料分开

| 类别 | 位置 | 职责 | 不代表 |
|---|---|---|---|
| **来源证据** | `研究资料/来源证据/` | 文献证据表、网页核查、图像分析、来源快照与工作图像 | 不是主题结论；工作副本不替代原页 |
| **村落资料** | `研究资料/村落资料/` | 敕木山、大张坑的资料索引、管理表、提取表与缺口 | 不是正式样本；文件数不是建筑数 |
| **对象候选** | `研究资料/对象候选/` | 按村落汇集的候选底稿、场地草图 | 不是正式名录或已确认单体 |
| **文献证据汇总** | `研究资料/文献证据汇总/` | 某一调查时点的文献汇总表 | 不是2026现状或全县存量 |

外部工具说明、技能快照不属于研究证据；可以留在来源证据目录作来源快照，但必须在入口说明“工具参考，不是研究证据”，正式方法取舍仍写进项目管理或成果包。

## 二、来源与时点必须能回到原处

新增或大修资料页时，至少写清：

- `type`：source-evidence／village-material／candidate-object／literature-summary／index。
- `status`：working-draft／reviewed／delivered／historical／generated 等，具体词按文件实际状态写。
- `scope`：这份资料覆盖什么对象、村落、文献或时段。
- `source_reviewed` 或 `date`：来源核对／调查／整理的时间点；不能用文件修改时间代替。
- `boundary`：哪些是原文、哪些是工作判断、哪些未核实。

已有资料页不强制补齐所有字段；新增页至少写 `type`、`status`、`scope`，并在正文说明来源、时点和缺口。缺失项在索引中显示“未记录”，不补猜。

## 三、文件数、图像数和对象数分开

- 一个 PNG／JPG 是工作图像或页面副本，不是一处遗存、一栋建筑或一条独立证据。
- 村落资料的文件数、资料单元数、候选条数、住户数、建筑编号和建筑栋数分别记录，不能相加或互换。
- 文献证据表的“条数”是记录条数，不等于去重后的遗存数；候选实体组数也不等于建筑数。
- 原文中的“保存较好／已搬迁／荒废”等状态必须保留调查时点，不自动改写为2026现状。

## 四、原始材料与工作副本

- 原始 PDF 以 Zotero 为准；来源证据中的本地图像、截图和裁切件是工作副本，不能替代正式引用。
- 网页快照只保存当时可见内容，不声称是完整离线站点；外部资源缺失按快照限制记录。
- 图像裁切、去重和实体候选可以迭代，但必须保留原图、原页、图注和来源；不以新裁切覆盖原图。
- 村落资料优先从分村索引进入原证据，不以汇总页替代原文件。

## 五、索引与生成

- `研究资料/资料总索引.md` 与 `研究资料/README.md` 的目录摘要由 `项目管理/健康检查/materials_views.py` 从目录与入口文件生成。
- 不手工编辑 README 中 `<!-- materials-catalog:start -->` 与 `<!-- materials-catalog:end -->` 之间的内容；增删目录或入口后运行生成器。
- 生成器只统计文件和链接，不判断证据充分性、对象身份或建筑数量。
- 检查：`python 项目管理/健康检查/materials_views.py --check`；发布先生成到 Paper 外，再由 `mac-paper` 按当前 SHA 写回。

## 六、归档与迁移

- 原始证据、村落资料和候选资料不因日期早而归档；仍有追溯价值的来源快照保留原位置。
- 只有被明确替代的旧整理稿、一次性汇报或失效中间文件才进入 `archive/`，并保留原路径映射。
- 不批量重命名或移动原始资料；确需迁移时先修引用、保留恢复说明，再按实际文件树验收。
- 资料“已交付”“已索引”“已核读”分别表示文件、导航和阅读状态，不自动提升为研究结论或实证验证。
