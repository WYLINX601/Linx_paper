# 对象候选

本目录保存按村落汇集的建筑群、单体与构件候选，以及现场／场地草图。候选信息用于范围讨论和后续核实，不是正式样本名录，也不是已确认的建筑身份。

## 入口

- [[研究资料/对象候选/研究对象候选汇总-按村落.md|研究对象候选汇总-按村落]]：候选底稿，配合导师浏览版和来源证据使用。
- [[研究资料/对象候选/场地调研 2026-11-02 14.17.09.excalidraw.md|场地调研草图]]：工作草图，不替代现场记录或正式测绘。

## 边界

- 候选的村落、名称、数量和图像线索必须回到来源证据；同名不自动合并，异写不自动拆分。
- 候选条数、图像数和村落统计不能相加为建筑栋数或有效样本数。
- 进入正式样本前，仍需对象身份、地点、时点、现状和资料可用性核查。
- 具体研究对象边界以[[context/PROJECT_CONTEXT.md|项目上下文]]和主题研究为准，本目录不另下结论。
